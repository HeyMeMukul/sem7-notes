6.1 ANN basics and architecture

An artificial neural network is a graph of simple processing units (neurons) connected by weighted links.

Q1Explain ANN with its architecture. Describe the architecture of an artificial neural network.

5–6 marks★★★ 3×

Asked in: 2022 Nov Q7(a) [5] · 2023 May Q7(a) [5 — building blocks] · 2025 Nov Q7(a) [6]

Definition

An Artificial Neural Network (ANN) is a computational model inspired by the brain. It consists of many interconnected neurons arranged in layers. Each connection has a weight; each neuron adds a bias, computes a weighted sum, and passes it through an activation function.

y = f( Σi=1..n wi xi + b )

Architecture

INPUT LAYER HIDDEN LAYER(S) OUTPUT LAYER x1 o ---- w11 ----\ \ \ x2 o ---- w12 -------o h1 ---\ \ / \ x3 o ---- w13 ----/ \ w_out \ o ---------> y x4 o ---- w14 -------o h2 ---/ \ / / x5 o ---- w15 ----/ / ... / (weights) / (bias b) Each circle = neuron; each arrow = weighted connection. Hidden layers learn features; output layer gives the prediction.

Layers

LayerFunction
Input layerReceives the raw features; no computation (sometimes only scaling)
Hidden layer(s)Learn intermediate features/representations; apply weights, bias and activation
Output layerProduces the final prediction (class probability or regression value)

Learning

Training adjusts the weights and biases to minimise a loss function. The most common method is backpropagation with gradient descent:

wij ← wij − η ∂L/∂wij

Why ANN works

  • Non-linear — activation functions let it learn curved boundaries.
  • Universal approximator — an MLP with enough hidden units can approximate any continuous function.
  • Feature learning — hidden layers learn features automatically.
  • Parallel — many neurons compute at once (GPU-friendly).
  • Robust — distributed representation tolerates noise and partial inputs.

Applications

Image classification, speech recognition, natural language processing, medical diagnosis, fraud detection, recommendation systems, forecasting.

Q3Explain in brief the types of ANN based on layers.

5 marks★ 1×

Asked in: 2022 Nov Q8(a) [5]

1. Single-layer network

Only an input layer and an output layer (no hidden layer). Each input connects directly to every output. It can solve only linearly separable problems (AND, OR — not XOR).

2. Multi-layer network (MLP)

One or more hidden layers between input and output. It can learn non-linear boundaries and approximate complex functions. It is trained by backpropagation.

3. Deep neural network

An MLP with many hidden layers (often dozens). Each layer learns increasingly abstract features: edges → shapes → objects. Used in image, speech and language tasks.

4. Specialised layered architectures

  • CNN — convolution + pooling layers for grid/image data.
  • RNN — recurrent hidden state for sequences.
  • Autoencoder — encoder/decoder layers for compression and denoising.

Comparison

6.2 Perceptron, single-layer network and MLP

Q1Explain artificial neural network based on the perceptron concept with a diagram.

6 marks★ 1×

Asked in: 2023 May Q8(a) [6]

Perceptron model

The perceptron is the simplest neuron. It computes a weighted sum of inputs, adds a bias, and applies a step function.

z = Σ wi xi + b      y = 1 if z ≥ 0, else 0
x1 o ---- w1 ----\ \ x2 o ---- w2 -------[ Σ + b ]----[ step ]----> y (0/1) / x3 o ---- w3 ----/ bias = 1 ---- w0 ----/

Learning rule

For each training sample, if the output is wrong:

wi ← wi + η (t − y) xi
b ← b + η (t − y)

where t = target, y = actual output, η = learning rate. If the prediction is correct, no update is made.

Example — AND gate

With weights w1 = w2 = 1 and bias = −1.5:

x1x2z = x1 + x2 − 1.5y
00−1.50
01−0.50
10−0.50
110.51

Limitations

  • Only linearly separable problems; cannot solve XOR.
  • Step function is not differentiable → cannot use gradient descent.
  • No hidden layer, so no feature learning.
  • Sensitive to initial weights and learning rate.

The XOR limitation is why we need multilayer networks and backpropagation.

Q3Write a note on single-layer neural networks.

4 marks★ 1×

Asked in: 2023 Nov Q7(a) [4]

Structure

A single-layer network has an input layer and an output layer, with no hidden layer. Every input is connected to every output.

x1 o ----\ x2 o ------> [ output neuron ] ----> y x3 o ----/ (weights on each arrow)

Properties

  • Computes a linear combination followed by an activation.
  • Can solve linearly separable problems (AND, OR, NOT).
  • Trained by the perceptron rule or the delta rule (LMS).
  • Fast and simple, but cannot solve XOR or learn complex patterns.

Use

Binary classification with a linear boundary, simple logic gates, and as the output layer of a larger network.

Q4What is a multilayer perceptron? Describe it with a diagram. Describe a multi-layer neural network and explain why backpropagation is required.

6 marks★★★ 3×

Asked in: 2023 May Q8(b) [6] · 2024 May Q7(a) [6] · 2025 Nov Q8(a) [6]

Definition

A Multilayer Perceptron (MLP) is a feed-forward neural network with at least one hidden layer between the input and output layers. Every neuron in one layer connects to every neuron in the next layer (fully connected).

Diagram

INPUT HIDDEN 1 HIDDEN 2 OUTPUT x1 o --------- o ------------- o -------------\ \ / \ / \ \ x2 o ------ o o --------- o o ------------- o ----> y1 \ / \ / \ / / x3 o ---- o o ------------- o o ---------/ \ / \ / \ / x4 o -- o o --------- o o ---------/----> y2 (weights) (weights) (weights) Each layer is fully connected to the next. Hidden layers use non-linear activation (ReLU/tanh).

Forward pass

a(1) = f(W(1)x + b(1))
a(2) = f(W(2)a(1) + b(2))
ŷ = f(W(3)a(2) + b(3))

Why backpropagation is required

  • The output error depends on the hidden-layer weights, but there is no direct target for a hidden neuron.
  • Backpropagation uses the chain rule to send the error gradient backwards through the network.
  • It tells every hidden weight whether increasing or decreasing it will reduce the loss.
  • Without it, training a deep network by trial and error would be impossible.
  • The perceptron rule cannot be applied to hidden layers because it needs the target output of each neuron.

Why MLP is powerful

  • Non-linear activation → non-linear decision boundaries.
  • Universal approximation: one hidden layer with enough units can approximate any continuous function.
  • Learns hierarchical features.
  • Works for classification (softmax) and regression (linear output).

XOR example

A single perceptron cannot separate XOR. An MLP with two hidden neurons can: the first hidden neuron detects “at least one input is 1” (OR), the second detects “both inputs are 1” (AND), and the output computes OR − AND, which is exactly XOR.

6.3 Backpropagation learning

Backpropagation = forward pass to compute the error + backward pass to distribute the error gradient + gradient-descent weight update.

Q1Write a short note on the backpropagation network. Describe the characteristics of the backpropagation algorithm.

6 marks★★ 2×

Asked in: 2022 Nov Q7(c) [6] · 2023 May Q7(b) [6 — characteristics]

Definition

Backpropagation (backward propagation of errors) is the supervised learning algorithm for multilayer networks. It computes the gradient of the loss with respect to every weight using the chain rule, then updates the weights by gradient descent.

Three stages

  1. Forward pass — feed the input, compute activations layer by layer, get the output.
  2. Error computation — compare output with target using a loss (MSE or cross-entropy).
  3. Backward pass — propagate the error gradient from output to input and update weights.

Key equations

Output delta:  δo = (t − y) · f′(neto)
Hidden delta:  δh = f′(neth) · Σk whk δk
Weight update:  wij ← wij + η δj xi
Bias update:  bj ← bj + η δj

Characteristics

  • Supervised — needs input–target pairs.
  • Gradient-based — uses the derivative of the activation function; it needs differentiable activations (sigmoid, tanh, ReLU).
  • Chain rule — the error is propagated backwards layer by layer.
  • Iterative — one pass is called an epoch; training repeats until convergence.
  • Local minima — can get stuck in a local minimum because the loss is non-convex.
  • Learning rate sensitive — too high diverges, too low is slow.
  • Credit assignment — it solves the problem of assigning error blame to hidden neurons.
  • Convergence — slower than the perceptron rule but much more powerful.

Advantages / disadvantages

AdvantagesDisadvantages
Trains multilayer networksSlow convergence
Generalises to unseen dataCan stuck in local minima
Works with many activation/loss functionsNeeds careful learning-rate tuning
Efficient gradient computationCan overfit; needs regularization

Q2Explain the concept of backpropagation in ANN with an example.

8 marks★ 1×

Asked in: 2023 Nov Q8(a) [8]

Network used

2 inputs → 2 hidden neurons → 1 output. All neurons use the sigmoid function. Initial weights:

ConnectionWeight
x1 → h10.5
x2 → h10.4
x1 → h2−0.3
x2 → h20.2
h1 → y0.6
h2 → y−0.5

Bias = 0 for all neurons. Input x = (1, 0), target t = 1, learning rate η = 0.5.

Step 1 — forward pass

neth1 = 0.5×1 + 0.4×0 = 0.5  →  h1 = σ(0.5) = 1/(1+e−0.5) = 0.6225
neth2 = −0.3×1 + 0.2×0 = −0.3  →  h2 = σ(−0.3) = 0.4256
nety = 0.6×0.6225 + (−0.5)×0.4256 = 0.3735 − 0.2128 = 0.1607
y = σ(0.1607) = 0.5401

Error = ½(t − y)² = ½(1 − 0.5401)² = 0.1058.

Step 2 — output delta

δo = (t − y) · y(1 − y)
δo = (1 − 0.5401) × 0.5401 × 0.4599 = 0.1142

Step 3 — hidden deltas

δh1 = δo · wh1→y · h1(1 − h1)
= 0.1142 × 0.6 × 0.6225 × 0.3775 = 0.0161

δh2 = 0.1142 × (−0.5) × 0.4256 × 0.5744 = −0.0140

Step 4 — weight updates (η = 0.5)

WeightFormulaChangeNew value
wh1→yη δo h1 = 0.5×0.1142×0.6225+0.03560.6356
wh2→yη δo h2 = 0.5×0.1142×0.4256+0.0243−0.4757
wx1→h1η δh1 x1 = 0.5×0.0161×1+0.00810.5081
wx1→h2η δh2 x1 = 0.5×(−0.0140)×1−0.0070−0.3070

Weights from x2 do not change because x2 = 0. This is a property of backprop: a zero input contributes zero gradient.

Step 5 — new error

new h1 = σ(0.5081) = 0.6244, new h2 = σ(−0.3070) = 0.4239
new y = σ(0.6356×0.6244 + (−0.4757)×0.4239) = σ(0.1952) = 0.5486
new error = ½(1 − 0.5486)² = 0.1019

The error fell from 0.1058 to 0.1019 after one pass. Repeat forward + backward for many epochs; the error keeps decreasing.

6.4 FLANN and RBF networks

Q1What is a Functional Link Artificial Neural Network (FLANN)? Explain its merits over other ANNs.

5 marks★ 1×

Asked in: 2023 Nov Q8(b) [5]

Definition

FLANN is a single-layer network with no hidden layer. Before learning, the input vector is expanded by a set of non-linear functions (the “functional expansion”). The expanded vector is then fed to a single-layer perceptron.

Input: x = [x1, x2]
Expansion: [x1, x2, sin(πx1), cos(πx1), sin(πx2), cos(πx2), x1x2, x1², x2², …]
Output: y = f( Σ wj φj(x) + b )

Architecture

x1 ----> [ functional expansion ] ----> φ1, φ2, ..., φm ----> [ single-layer ] ----> y x2 ----> (sin, cos, products, powers) perceptron (weights w) No hidden layer: the expansion does the non-linear mapping.

Why it works

A linear perceptron can only draw a straight boundary. By adding non-linear terms (sin, cos, products), the same linear learner can separate a non-linear region in the original space. The expansion raises the dimension; the learning stays linear and fast.

Merits over other ANNs

  • No hidden layer → much fewer weights and faster training.
  • Simple learning — the delta rule / LMS converges quickly; no backpropagation.
  • Less computational cost than MLP with the same approximation power for many problems.
  • No local minima problem of deep networks for the single-layer case (convex loss).
  • Good for non-linear system identification, function approximation and signal processing.
  • Fewer hyperparameters — mainly the expansion order and learning rate.

Limitations

  • The expansion must be chosen by hand; too many terms cause overfitting.
  • Not as flexible as a deep network for complex image/text tasks.
  • Memory grows with the number of expansion terms.

Q2Explain Radial Basis Function (RBF) networks in detail. Explain the building blocks of RBF networks.

6–8 marks★★★ 3×

Asked in: 2023 Nov Q7(b) [8] · 2024 May Q8(a) [6 — building blocks] · 2025 Nov Q7(c) [6 — building blocks]

Definition

An RBF network is a feed-forward network with three layers: an input layer, a hidden layer of radial basis functions, and a linear output layer. Each hidden neuron responds strongly only when the input is close to its centre.

Architecture

INPUT RBF HIDDEN LAYER LINEAR OUTPUT x1 o -------- φ1(x) = exp(-||x-c1||² / 2σ1²) ----\ \ / \ x2 o ---- φ2(x) = exp(-||x-c2||² / 2σ2²) --------- o ----> y = Σ wj φj(x) + b \ / / x3 o -- φ3(x) = exp(-||x-c3||² / 2σ3²) ---------/ (each unit has a centre cj and width σj)

Building blocks

BlockRole
Input layerReceives the feature vector x
RBF hidden unitsCompute φj(x); each is a Gaussian “bump” centred at cj
Centres cjPositions in input space where the unit is most active; found by k-means or random selection
Widths σjControls how far the influence of the unit reaches; often set by a heuristic (e.g. average distance to nearest centres)
Output weights wjLinear weights combined with the hidden activations; trained by least squares or LMS
Output bias bShifts the final output

Gaussian RBF

φj(x) = exp( − ‖x − cj‖² / (2σj²) )
y(x) = Σj=1..m wj φj(x) + b

φ is 1 at the centre and falls smoothly to 0 far away. The output is a weighted sum of bumps.

Training (3 steps)

  1. Choose centres — k-means on the input data, or randomly pick m points.
  2. Choose widths — e.g. σ = average distance to the nearest few centres, or a single width for all units.
  3. Train output weights — the hidden layer is fixed, so the output is linear in w. Solve the linear least-squares problem (or use the delta rule).

Example

For a 1-D input, two centres c1 = 2, c2 = 8 with σ = 1. An input x = 2.5 gives φ1 = exp(−0.25/2) = 0.882, φ2 = exp(−30.25/2) ≈ 0. The output is almost entirely determined by the first unit. This is why RBF networks are called local approximators.

RBF vs MLP

PointRBF networkMLP
Hidden unitsRadial basis (Gaussian)Sigmoid/ReLU neurons
NatureLocal approximationGlobal approximation
Hidden layer trainingUnsupervised (centres) or fixedSupervised backpropagation
Output layerLinearNon-linear (usually)
Training speedFast (linear least squares)Slower (gradient descent)
Data needMore units for high dimensionsGood for high dimensions
InterpretationCentres are prototypesWeights are distributed

Advantages / disadvantages

AdvantagesDisadvantages
Fast training; no backprop through hidden layerMany hidden units in high dimensions
Good interpolation and function approximationChoice of centres/widths is critical

6.5 Activation functions

The activation function decides whether a neuron fires and adds the non-linearity that makes deep learning possible.

Q1What is an activation function? Explain with a suitable example. Discuss any two activation functions with example.

4–5 marks★★ 2×

Asked in: 2023 May Q8(c) [5 — two functions] · 2023 Nov Q8(c) [4 — definition + example]

Definition

An activation function is a mathematical function applied to the weighted sum of a neuron. It decides the neuron’s output and introduces non-linearity.

y = f( Σ wixi + b )

(i) Binary sigmoid

f(x) = 1 / (1 + e−x)     range (0, 1)
  • Smooth S-shape; differentiable everywhere.
  • Output can be read as a probability.
  • Used in binary classification output layers.
  • Problem: vanishing gradient for very large |x|.

Example: x = 0 → f = 0.5; x = 2 → f = 0.881; x = −2 → f = 0.119.

(ii) Bipolar sigmoid (tanh)

f(x) = (1 − e−x) / (1 + e−x) = tanh(x/2)    range (−1, 1)
  • Zero-centred, so gradient updates are better conditioned than sigmoid.
  • Used in hidden layers of MLPs and RNNs.
  • Still saturates at the extremes.

Example: x = 0 → 0; x = 2 → 0.762; x = −2 → −0.762.

Other common functions

FunctionFormulaRangeUse
Step1 if x ≥ 0 else 0{0,1}Perceptron
Identityx(−∞,∞)Regression output
ReLUmax(0,x)[0,∞)Deep hidden layers
Leaky ReLUmax(0.01x,x)(−∞,∞)Avoids dead neurons

Q2What are the different activation functions used in neural networks?

6 marks★ 1×

Asked in: 2024 May Q7(b) [6]

1. Identity / linear

f(x) = x

No non-linearity. Used only in the output layer of a regression network. A network with only linear activations collapses to a single linear function.

2. Binary step / threshold

f(x) = 1 if x ≥ 0, else 0

The original perceptron. Not differentiable at 0, so it cannot be trained by gradient descent.

3. Sigmoid

f(x) = 1/(1+e−x)

Squashes to (0,1). Good for probabilities; suffers from vanishing gradients and is not zero-centred.

4. Tanh (bipolar sigmoid)

f(x) = tanh(x)

Squashes to (−1,1), zero-centred. Better than sigmoid for hidden layers, still saturates.

5. ReLU

f(x) = max(0, x)

Cheap, non-saturating for positive x, sparse activation. The default for deep networks. Problem: “dead ReLU” if a unit always gets negative input.

6. Leaky ReLU / Parametric ReLU

f(x) = x if x > 0, else αx (α = 0.01)

Keeps a small gradient for negative inputs, so neurons do not die.

7. Softmax

f(xi) = exi / Σj exj

Converts a vector of scores into a probability distribution that sums to 1. Used in the output layer of multiclass classifiers.

8. Swish / GELU (modern)

Smooth variants used in deep networks; often give slightly better accuracy than ReLU.

Q3Write a short note on the importance of activation functions in neural networks. What is the role of activation functions, and why are they necessary for learning?

5–6 marks★★ 2×

Asked in: 2025 May Q7(a) [5] · 2025 Nov Q8(c) [6]

Why they are necessary

  1. Non-linearity — without an activation, stacking layers is useless: a composition of linear functions is still linear. The network could only draw a straight boundary no matter how deep it is.
  2. Decision making — the activation decides whether a neuron fires and how strongly.
  3. Bounded outputs — sigmoid/tanh keep values in a fixed range, which stabilises training and allows probability interpretation.
  4. Differentiability — sigmoid, tanh and ReLU have gradients, so backpropagation can update the weights.
  5. Feature selection — ReLU outputs zero for negative inputs, producing sparse activations.

Role in learning

The gradient of the loss with respect to a weight includes the derivative of the activation:

∂L/∂wij = δj · xi    where δj contains f′(netj)

If f′ is zero (saturation or dead ReLU), the weight stops learning. This is why the choice of activation affects convergence speed and final accuracy.

Choosing an activation

LayerTypical choiceReason
Hidden (deep)ReLU / Leaky ReLUFast, no saturation for positive values
Hidden (RNN)tanhZero-centred, bounded state
Binary outputSigmoidProbability of class 1
Multiclass outputSoftmaxProbabilities sum to 1
Regression outputIdentityNo range restriction
One-line answer: activation functions inject non-linearity and differentiability. Without them, a deep network is just one linear model; with them, it can approximate complex functions and train by backpropagation.

6.6 Recurrent neural networks (RNN)

An RNN has a memory: the hidden state from the previous time step is fed back into the current step.

Q1What is a recurrent neural network? Explain with a suitable example. Explain RNN and its applications in brief.

5–6 marks★★★★★★ 6×

Asked in: 2022 Nov Q8(b) [6] · 2023 Nov Q7(c) [5 — applications] · 2024 May Q8(c) [6] · 2025 Nov Q7(b) [6] · related: 2023 May Q7(c) [6], 2025 May Q7(b) [6]

Definition

An RNN is a neural network for sequential data. It processes one element at a time and keeps a hidden state that carries information from previous elements. The same weights are reused at every time step.

ht = f( Wh ht−1 + Wx xt + bh )
yt = g( Wy ht + by )

Unrolled diagram

y1 y2 y3 ^ ^ ^ | | | [h1] -------> [h2] -------> [h3] ---> ... ^ ^ ^ | | | [x1] [x2] [x3] Same weight matrices Wx, Wh, Wy at every step. The horizontal arrows are the memory (hidden state).

Why memory matters

In “The cat sat on the ___”, a feed-forward network sees only the current word. An RNN remembers “cat” and “sat”, so it can predict “mat”. The hidden state is a compressed summary of the past.

Types of RNN

TypeInput → outputExample
One-to-oneSingle → singlePlain classification
One-to-manySingle → sequenceImage captioning
Many-to-oneSequence → singleSentiment analysis
Many-to-manySequence → sequenceMachine translation

Applications

  • Language modelling and text generation.
  • Machine translation (seq2seq).
  • Speech recognition.
  • Sentiment classification.
  • Time-series forecasting (stock, weather, sales).
  • Handwriting recognition and video analysis.

Training and problems

RNNs are trained by backpropagation through time (BPTT): the network is unrolled and the error is propagated backwards through every time step.

  • Vanishing gradient — long sequences make gradients shrink to zero; the network forgets long-range dependencies.
  • Exploding gradient — gradients grow without bound; use gradient clipping.
  • Slow — sequential computation cannot be fully parallelised.

Solutions: LSTM (input, forget, output gates), GRU (reset and update gates), gradient clipping, truncated BPTT.

6.7 Convolutional neural networks (CNN)

A CNN learns local patterns with shared filters, then pools them and classifies with fully connected layers.

Q1Explain the Convolutional Neural Network with a suitable example. Draw and explain the CNN architecture.

6 marks★★★★★ 5×

Asked in: 2022 Nov Q8(c) [6 — convolution layer + hidden layer] · 2023 May Q7(c) [6] · 2024 May Q7(c) [6] · 2025 May Q7(c) [6 — architecture] · 2025 Nov Q8(b) [6]

Definition

A CNN is a feed-forward deep network for grid data such as images. It uses convolution instead of full matrix multiplication, so it learns local features with far fewer parameters.

Architecture

INPUT CONV + ReLU POOL CONV + ReLU POOL FLATTEN FC SOFTMAX 32x32x3 ---> 28x28x8 -----> 14x14x8 --> 12x12x16 ----> 6x6x16 --> vector --> 128 --> 10 (5x5 filter) (2x2) (3x3 filter) (2x2) | | | | | | | | raw pixels edges shrink shapes shrink features classify probabilities

Layer by layer

LayerOperationPurpose
ConvolutionSlide a filter over the input; compute dot productsDetect edges, corners, textures
ReLUmax(0, x)Non-linearity; keeps positive activations

FlattenConvert feature maps to a vectorFeed to fully connected layers
Fully connectedStandard dense layerCombine features for classification

Convolution example

A 3×3 filter (edge detector) slides over a 5×5 image with stride 1 and no padding. The output is 3×3:

output size = (W − F + 2P)/S + 1 = (5 − 3 + 0)/1 + 1 = 3

Each output cell is the dot product of the filter and a 3×3 patch. The same filter is reused at every position → parameter sharing.

Example — digit recognition

Input 28×28 MNIST digit → conv 5×5, 8 filters → 24×24×8 → pool 2×2 → 12×12×8 → conv 3×3, 16 filters → 10×10×16 → pool → 5×5×16 → flatten 400 → dense 128 → softmax 10. The first layers detect edges, the deeper layers detect loops and strokes, and the classifier distinguishes 0–9.

Why CNN is better than a plain MLP for images

  • Local connectivity — a neuron sees a small patch, matching the local structure of images.
  • Parameter sharing — one filter is reused everywhere, so far fewer weights.
  • Translation invariance — pooling keeps the object recognisable even if it shifts.
  • Hierarchy — stacking layers builds edges → shapes → objects.

Convolution layer vs hidden layer (2022 Nov wording)

The convolution layer is a hidden layer: it produces hidden feature maps. In a CNN, “hidden layers” usually means the sequence of convolution + ReLU + pooling layers before the fully connected classifier. The convolution layer learns filters; the pooling layer reduces resolution; together they form the hidden representation.

Q2What are the different types of padding used in CNN?

6 marks★ 1×

Asked in: 2025 May Q8(b) [6]

Why padding is needed

Every convolution shrinks the image. Without padding, the border pixels are used less often, and deep networks lose spatial size quickly. Padding adds extra pixels around the border.

Output size = (W − F + 2P) / S + 1

1. Valid padding (P = 0)

  • No padding; the filter only sees complete patches.
  • Output shrinks by F − 1: 32×32 with 5×5 → 28×28.
  • Simple, but loses border information.

2. Same padding

  • Pad so that the output has the same width/height as the input (for stride 1).
  • For a 5×5 filter, P = 2; for 3×3, P = 1.
  • Formula: P = (F − 1)/2 for odd F and S = 1.
  • Most common in deep CNNs (VGG, ResNet).

3. Full padding

  • Pad by F − 1 on each side, so the filter is applied at every possible overlap.
  • Output is larger than the input: 32×32 with 5×5 → 36×36.
  • Rarely used; keeps maximum border information.

4. Causal padding (1-D / time series)

Pad only on the left so that the output at time t depends only on past inputs. Used in temporal CNNs to avoid looking into the future.

5. Zero vs other padding values

  • Zero padding — the default; adds zeros.
  • Reflection / replication — mirror or repeat border values; reduces edge artefacts.
  • Constant padding — any chosen constant.

Comparison table

TypeP32×32, 5×5, S=1Effect
Valid028×28Shrinks; no border padding
Same232×32Preserves size
Full436×36Enlarges; maximum overlap

Parameter count example

Conv layer: 3 input channels, 8 filters of 5×5, one bias per filter:

params = (5×5×3 + 1) × 8 = 76 × 8 = 608

A fully connected layer from 32×32×3 to 28×28×8 would need millions of weights. This is the advantage of parameter sharing.

Q3Write a short note on the layers used in CNN: (i) Convolutional layer (ii) Pooling layer.

6 marks★ 1×

Asked in: 2025 May Q8(c) [6]

(i) Convolutional layer

A set of learnable filters (kernels) slides over the input. At each position it computes the dot product between the filter and the patch, producing a feature map.

output(i,j) = Σm Σn input(i+m, j+n) · filter(m,n) + bias
  • Filter/kernel — small matrix (3×3, 5×5) learned during training.
  • Stride — how many pixels the filter moves each step; larger stride → smaller output.
  • Padding — zeros around the border to control output size.
  • Channels — each filter produces one feature map; multiple filters produce multiple maps.
  • Parameter sharing — the same filter is used at all positions.
  • ReLU usually follows to add non-linearity.

Example: a 3×3 vertical-edge filter [[-1,0,1],[-1,0,1],[-1,0,1]] gives a high response where the image changes from dark to bright horizontally.

(ii) Pooling layer

Pooling reduces the spatial size of feature maps. It has no learnable weights.

TypeOperationProperty
Max poolingTake the maximum in each windowKeeps the strongest feature; most common
Average poolingTake the averageSmoother; keeps overall activation
Global average poolingAverage the whole feature map to one numberReplaces the flatten + FC layers; reduces overfitting
  • Window size — usually 2×2 with stride 2, which halves the size.
  • Effect — fewer parameters, less computation, translation invariance.
  • No learning — pooling is a fixed operation.

Example

For the 2×2 window [[1,3],[2,4]], max pooling gives 4 and average pooling gives 2.5. A 4×4 feature map with 2×2 pooling becomes 2×2.

Typical block

CONV → ReLU → POOL → CONV → ReLU → POOL → FLATTEN → FC → SOFTMAX

6.8 Personalized recommendation

Q1What is personalized recommendation? What is content-based recommendation?

6 marks★ 1×

Asked in: 2024 May Q8(b) [6]

Personalized recommendation

A personalized recommendation system predicts what a specific user will like, based on the user’s past behaviour, preferences and the behaviour of similar users. The syllabus case study is a movie recommendation system.

  • Input: user profile, ratings, clicks, purchase history, item features.
  • Output: a ranked list of items the user is likely to enjoy.
  • Goal: reduce information overload and increase engagement/sales.

Content-based recommendation

Recommends items that are similar in content to items the user liked before. It builds an item profile (genre, director, keywords) and a user profile (aggregate of liked items), then measures similarity.

similarity(user, item) = cos( user_profile , item_profile )
cos(A,B) = (A·B) / (‖A‖‖B‖)

Example — movies

A user rated “Interstellar”, “Inception” and “The Martian” highly. Their profiles share sci-fi, space and Christopher Nolan. A new movie with the same genre/director gets a high cosine similarity and is recommended. A comedy is not recommended because its feature vector points in a different direction.

Content-based vs collaborative

PointContent-basedCollaborative filtering
UsesItem features + user’s own historyRatings of many users
SimilarityItem–item / user–item featuresUser–user or item–item ratings
Cold startNeeds item features; new user is hardNew item/user is hard
SerendipityLow — recommends similar itemsHigher — discovers unexpected items
Example“More sci-fi movies like this”“Users who liked this also liked…”

Hybrid systems

Combine content-based and collaborative scores (weighted sum, stacking or switching) to overcome the weaknesses of each. Most real systems (Netflix, Amazon, Spotify) are hybrid.

Evaluation

  • Precision@K, recall@K, NDCG, hit rate.
  • Online: click-through rate, watch time, conversion.
  • Coverage, diversity and novelty for long-term user satisfaction.
