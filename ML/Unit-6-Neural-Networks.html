6.1 ANN basics and architecture

An artificial neural network is a graph of simple processing units (neurons) connected by weighted links.

Q1Explain ANN with its architecture. Describe the architecture of an artificial neural network.

5–6 marks★★★ 3×

Asked in: 2022 Nov Q7(a) [5] · 2023 May Q7(a) [5 — building blocks] · 2025 Nov Q7(a) [6]

In simple words: An artificial neural network is a graph of small decision-makers called neurons.
Each neuron takes inputs, multiplies them by weights, adds a bias, and passes the result through an activation.
Neurons are arranged in layers: input, hidden and output.

Why we do this

Some patterns are too complex for a hand-written rule. An ANN learns the rule from examples by adjusting its weights. With hidden layers and non-linear activations, it can model curved boundaries and high-level features.

Words you need first

  • Artificial neural network (ANN) — a network of simple computing units connected by weighted links.
  • Neuron (node/unit) — one computing unit that sums weighted inputs and applies an activation.
  • Weight — a learnable number that says how strongly one neuron affects another.
  • Bias — a constant added to a neuron’s sum; it shifts the activation.
  • Activation function — a non-linear function applied to the weighted sum.
  • Layer — a group of neurons at the same stage of processing.
  • Loss function — a number that measures how wrong the prediction is.
  • Gradient descent — repeatedly moving weights in the direction that lowers the loss.
  • Backpropagation — the algorithm that computes the gradient for every weight using the chain rule.
  • Epoch — one full pass over the training data.
  • Hidden layer — a layer between input and output whose values are not in the data.
  • Universal approximator — a model that can approximate any continuous function given enough units.
  • Feature learning — learning useful representations automatically instead of hand-coding them.
  • GPU — a chip that performs many parallel calculations, useful for neural networks.
  • Deep network — a network with many hidden layers.

Step-by-step

  1. Send the input through the input layer. The raw features are passed to the hidden layer.
  2. Compute each hidden neuron. Multiply inputs by weights, add the bias, and apply the activation.
  3. Pass the hidden values to the output layer. The output layer produces the prediction.
  4. Measure the loss. Compare the prediction with the target.
  5. Send the error backward. Backpropagation computes how much each weight contributed to the loss.
  6. Update the weights. Take a small step opposite to the gradient.
  7. Repeat for many epochs. Stop when the loss stops improving or a validation score starts to worsen.

The neuron equation

y = f( Σi=1..n wi xi + b )

What this means: the neuron adds up every input × weight, adds the bias, then applies the activation f. The weights decide what matters; the bias shifts the decision; f adds the bend.

Architecture

INPUT LAYER HIDDEN LAYER(S) OUTPUT LAYER x1 o ---- w11 ----\ \ \ x2 o ---- w12 -------o h1 ---\ \ / \ x3 o ---- w13 ----/ \ w_out \ o ---------> y x4 o ---- w14 -------o h2 ---/ \ / / x5 o ---- w15 ----/ / ... / (weights) / (bias b) Each circle = neuron; each arrow = weighted connection. Hidden layers learn features; output layer gives the prediction.

What this means: the input layer holds the features, the hidden layers build intermediate representations, and the output layer gives the answer. Every arrow is a weight, and every neuron has a bias.

Layers

LayerFunction
Input layerReceives the raw features; no computation (sometimes only scaling)
Hidden layer(s)Learn intermediate features/representations; apply weights, bias and activation
Output layerProduces the final prediction (class probability or regression value)

What this means: the input layer is mostly a holding area. The hidden layers do the feature learning. The output layer formats the answer as a class probability or a regression value.

Learning

Training adjusts the weights and biases to minimise a loss function. The most common method is backpropagation with gradient descent:

wij ← wij − η ∂L/∂wij

What this means: η is the learning rate, and ∂L/∂wij is the gradient: the direction and steepness in which the loss changes when that weight changes. Subtract a small multiple of the gradient to move downhill.

Why ANN works

  • Non-linear — activation functions let it learn curved boundaries.
  • Universal approximator — an MLP with enough hidden units can approximate any continuous function.
  • Feature learning — hidden layers learn features automatically instead of relying on hand-crafted rules.
  • Parallel — many neurons compute at once, which suits GPUs.
  • Robust — a distributed representation tolerates noise and partial inputs.

Applications

Image classification, speech recognition, natural language processing, medical diagnosis, fraud detection, recommendation systems and forecasting.

Real-life analogy: a factory assembly line. Raw materials enter at one end. Each workstation (layer) performs one transformation and passes the result on. The final station produces the finished product. If the product is faulty, the feedback travels back down the line so each station can adjust its settings.
Common confusion: “neural” does not mean the network copies the brain; it is only loosely inspired by neurons. The input layer usually does no computation. And “deep” means many hidden layers, not many inputs or many outputs.

Q2What are the building blocks of a neural network? Elaborate.

5 marks★ 1×

Asked in: 2023 May Q7(a) [5]

In simple words: A neural network is built from a few standard parts.
Neurons do the adding, weights store the importance, bias shifts the decision, and activation adds the bend.
Layers organise the neurons, and the loss plus optimiser drive the learning.

Why we do this

Exam questions often ask for the building blocks by name. Knowing each part’s job also helps you debug a network: a bad learning rate, a missing activation, or the wrong loss all produce different failures. The blocks are the vocabulary of every architecture you will meet later.

Words you need first

  • Neuron (node/unit) — the unit that receives inputs, computes a weighted sum plus bias, and applies an activation.
  • Weight — a learnable strength on one connection; the main memory of the network.
  • Bias — a learnable constant that shifts a neuron’s activation.
  • Activation function — a non-linear function such as sigmoid, tanh, ReLU or softmax.
  • Layer — a group of neurons at one stage: input, hidden or output.
  • Loss function — the error measure the network tries to minimise.
  • Optimiser — the algorithm that updates weights, such as gradient descent, SGD or Adam.
  • Learning rate (η) — the size of each weight update.
  • MSE — mean squared error, a loss for regression.
  • Cross-entropy — a loss for classification that punishes confident wrong answers.
  • Hidden layer — a layer between input and output that learns intermediate features.
  • SGD — stochastic gradient descent; updates weights from small batches of data.
  • Adam — an optimiser that adapts the step size for each weight.

Step-by-step

  1. Build a neuron. Give it weights, a bias and an activation. This is the basic computing unit.
  2. Stack neurons into layers. The input layer receives features; hidden layers transform them; the output layer makes the prediction.
  3. Connect the layers. In a dense network, every neuron in one layer connects to every neuron in the next.
  4. Choose a loss. Use MSE for regression and cross-entropy for classification.
  5. Choose an optimiser and learning rate. The optimiser decides how to use the gradients; the learning rate decides how far to step.
  6. Train. Forward pass → loss → backward pass → weight update → repeat.

The building blocks

Building blockRole
Neuron (node/unit)Receives inputs, computes weighted sum + bias, applies activation, sends output
Weights (w)Learnable strength of each connection; the main memory of the network
Bias (b)Shifts the activation; allows the neuron to fire even when all inputs are zero
Activation functionAdds non-linearity: step, sigmoid, tanh, ReLU, softmax
LayersInput, hidden and output layers organise the neurons
Loss functionMeasures the error: MSE for regression, cross-entropy for classification
OptimiserUpdates weights: gradient descent, SGD, Adam
Learning rate (η)Controls the step size of each update

What this means: a neuron without weights cannot learn; a weight without a bias cannot shift its threshold; an activation without a loss has nothing to optimise. The blocks only work as a system.

Biological analogy

DendritesInputs

SynapseWeight
AxonOutput
Firing thresholdActivation function

What this means: the comparison is loose. Real neurons are far more complex. The useful part is the idea of inputs arriving through connections, a cell body summing them, and a threshold deciding whether to fire.

Real-life analogy: a car has an engine, fuel lines, a steering wheel, a dashboard and a driver. The neuron is the engine; weights are the fuel settings; bias is the idle adjustment; activation is the steering response; the loss is the dashboard warning; the optimiser is the driver correcting the course.
Common confusion: the bias is not a weight on a real input; it is a separate constant with its own learnable value. The learning rate is not the number of epochs; it is the step size within each update. And the loss is not the activation: the loss measures the final error, while the activation shapes each neuron’s output.

Q3Explain in brief the types of ANN based on layers.

5 marks★ 1×

Asked in: 2022 Nov Q8(a) [5]

In simple words: Networks are grouped by how many hidden layers they have.
A single-layer network has none. A multilayer network has one or more. A deep network has many.
Specialised networks such as CNNs and RNNs add their own layer types for images or sequences.

Why we do this

Depth controls what a network can represent. A shallow network can draw a straight boundary; a deeper one can build a hierarchy of features. Knowing the categories helps you choose the right architecture and explain its limits.

Words you need first

  • Single-layer network — input connected directly to output, with no hidden layer.
  • Multilayer network (MLP) — a network with at least one hidden layer.
  • Deep neural network — a network with many hidden layers.
  • Linear decision boundary — a boundary that is a straight line or flat plane.
  • Non-linear decision boundary — a curved boundary that a linear model cannot draw.
  • CNN — a network with convolution and pooling layers, used for images and grids.
  • RNN — a network with a recurrent hidden state, used for sequences.
  • Autoencoder — a network that compresses input into a smaller code and reconstructs it.
  • MLP — multilayer perceptron; a fully connected network with at least one hidden layer.
  • Hidden layer — a layer between input and output.
  • Overfitting — memorising the training data and failing on new data.
  • Adaline — an early linear neuron trained by the delta rule.

Step-by-step

  1. Count the hidden layers. Zero → single-layer. One or two → multilayer. Many → deep.
  2. Check the data type. Grids and images → CNN. Sequences → RNN. General tables → MLP.
  3. Check the task. Compression or denoising → autoencoder. Classification → softmax output. Regression → linear output.
  4. Match depth to difficulty. More layers can learn more abstract features, but they need more data and careful training.
  5. State the trade-off. Deeper is not automatically better; it can overfit and become harder to train.

1. Single-layer network

Only an input layer and an output layer, with no hidden layer. Each input connects directly to every output. It can solve only linearly separable problems such as AND and OR, but not XOR.

2. Multi-layer network (MLP)

One or more hidden layers between input and output. It can learn non-linear boundaries and approximate complex functions. It is trained by backpropagation.

3. Deep neural network

An MLP with many hidden layers, often dozens. Each layer learns increasingly abstract features: edges → shapes → objects. Deep networks are used in image, speech and language tasks.

4. Specialised layered architectures

  • CNN — convolution + pooling layers for grid and image data.
  • RNN — a recurrent hidden state for sequences.
  • Autoencoder — encoder and decoder layers for compression and denoising.

Comparison

TypeHidden layersDecision boundaryExample
Single-layer0LinearPerceptron, Adaline
Multi-layer1–2Non-linearMLP for XOR
DeepManyHighly non-linearResNet, VGG

What this means: the table is a rough guide, not a strict law. A “deep” network is still a multilayer network; the label simply says there are many hidden layers. The real difference is the complexity of the features the network can build.

Real-life analogy: one worker can handle a simple task alone. A small team can divide the work and combine results. A large company with many departments can build a complex product, but it also needs more coordination and more training. Depth is the number of management layers.
Common confusion: “deep” does not automatically mean “more accurate”. Very deep networks can overfit, vanish gradients or be hard to train. Also, a multilayer network usually means at least one hidden layer, not exactly two. And CNNs and RNNs are still layered networks; they are specialised, not a separate category outside neural networks.

6.2 Perceptron, single-layer network and MLP

Q4What is a multilayer perceptron? Describe it with a diagram. Describe a multi-layer neural network and explain why backpropagation is required.

6 marks★★★ 3×

Asked in: 2023 May Q8(b) [6] · 2024 May Q7(a) [6] · 2025 Nov Q8(a) [6]

In simple words: A multilayer perceptron is a stack of neuron layers.
The input layer receives the data, hidden layers learn combinations, and the output layer makes the prediction.
Backpropagation sends the error backward so every layer can adjust its weights.

Why we do this

A single perceptron can only draw a straight boundary, so it cannot solve XOR or recognise complex patterns. Adding one or more hidden layers gives the network a way to build curved boundaries and intermediate features. Backpropagation is the method that makes those hidden layers trainable.

Words you need first

  • Perceptron — the simplest neuron: a weighted sum followed by a threshold.
  • Hidden layer — a layer between input and output; its values are not given in the data.
  • Fully connected — every neuron in one layer connects to every neuron in the next.
  • Activation function — a non-linear function applied to a neuron’s weighted sum.
  • Forward pass — computing the output from input to output.
  • Loss — a number that measures how wrong the output is.
  • Backpropagation — using the chain rule to send the loss gradient backward through the layers.
  • Chain rule — a calculus rule for differentiating a function made of nested functions.
  • Universal approximation — the fact that a wide enough hidden layer can approximate any continuous function.
  • XOR — exclusive OR; its true/false pattern is not linearly separable.
  • Weight — a learnable strength on a connection.
  • Bias — a learnable constant added to a neuron’s sum.
  • Gradient — the direction and steepness of change of the loss.
  • Epoch — one full pass over the training data.
  • MSE / cross-entropy — common loss functions for regression and classification.

Step-by-step

  1. Feed the input forward. Each layer computes a weighted sum plus bias, then applies an activation.
  2. Get the output and compute the loss. Compare the prediction with the target using MSE or cross-entropy.
  3. Compute the output delta. This says how much the output needs to change and how sensitive the activation is.
  4. Send the error backward. Each hidden neuron receives blame from every neuron it feeds, weighted by the connection strength.
  5. Update every weight. Move each weight a small step opposite to its gradient.
  6. Repeat for many epochs. One epoch is one full pass over the training data.

Diagram

INPUT HIDDEN 1 HIDDEN 2 OUTPUT x1 o --------- o ------------- o -------------\ \ / \ / \ \ x2 o ------ o o --------- o o ------------- o ----> y1 \ / \ / \ / / x3 o ---- o o ------------- o o ---------/ \ / \ / \ / x4 o -- o o --------- o o ---------/----> y2 (weights) (weights) (weights) Each layer is fully connected to the next. Hidden layers use non-linear activation (ReLU/tanh).

What this means: the circles are neurons and the arrows are weighted connections. “Fully connected” means every circle in one column touches every circle in the next. The hidden columns are where the network builds its own intermediate features.

Forward pass

a(1) = f(W(1)x + b(1))
a(2) = f(W(2)a(1) + b(2))
ŷ = f(W(3)a(2) + b(3))

What this means: a(1) is the first hidden layer’s output. It is computed from the input x, then passed to the next layer. The final line produces the prediction ŷ. Without a non-linear f, all these layers would collapse into one linear transformation.

Why backpropagation is required

  • The output error depends on the hidden-layer weights, but there is no direct target for a hidden neuron.
  • Backpropagation uses the chain rule to send the error gradient backward through the network.
  • It tells every hidden weight whether increasing or decreasing it will reduce the loss.
  • Without it, training a deep network by trial and error would be impossible.
  • The perceptron rule cannot be applied to hidden layers because it needs the target output of each neuron.

Why MLP is powerful

  • Non-linear activation → non-linear decision boundaries.
  • Universal approximation: one hidden layer with enough units can approximate any continuous function.
  • It learns hierarchical features: simple combinations first, complex combinations later.
  • It works for classification (softmax output) and regression (linear output).

XOR example

A single perceptron cannot separate XOR. An MLP with two hidden neurons can: the first hidden neuron detects “at least one input is 1” (OR), the second detects “both inputs are 1” (AND), and the output computes OR − AND, which is exactly XOR.

Real-life analogy: a company has front-line workers, managers and a final decision-maker. Workers notice simple facts, managers combine those facts into a bigger picture, and the boss makes the call. When the call is wrong, the boss’s feedback travels back through the managers to the workers, so each person knows what to change next time.
Common confusion: an MLP is not “one perceptron with more inputs”; the hidden layers are the key. Backpropagation is a training method, not a network architecture. And “hidden” does not mean the data is secret; it means those neuron values are not part of the original dataset.

Q1Explain artificial neural network based on the perceptron concept with a diagram.

6 marks★ 1×

Asked in: 2023 May Q8(a) [6]

In simple words: A perceptron is a tiny decision-maker.
It multiplies each input by a weight, adds a bias, and checks whether the total crosses zero.
If the answer is wrong, it nudges the weights. That is the whole learning rule.

Why we do this

The perceptron is the building block of neural networks. Understanding it makes later ideas — layers, activation, backpropagation — easier. It also shows the first big limitation of linear models: they cannot solve XOR.

Words you need first

  • Perceptron — the simplest artificial neuron: weighted sum + bias + step function.
  • Weight (w) — how important one input is to the decision.
  • Bias (b) — a constant added to the weighted sum; it shifts the decision threshold.
  • Step function — outputs 1 when the input is at least 0, otherwise 0.
  • Learning rate (η) — how large each weight update is.
  • Target (t) — the correct answer for a training example.
  • Linearly separable — a dataset that can be split correctly by one straight line or plane.
  • Epoch — one full pass through the training data.
  • Decision boundary — the line or plane where the output switches from 0 to 1.
  • Convergence — the point where further updates stop improving the result.
  • AND gate — a logic gate that outputs 1 only when both inputs are 1.

Step-by-step

  1. Compute the weighted sum. Multiply each input by its weight and add them all.
  2. Add the bias. The bias moves the decision boundary without depending on any input.
  3. Apply the step function. If the total is at least 0, output 1; otherwise output 0.
  4. Compare with the target. If the output is correct, do nothing.
  5. If wrong, update the weights. Move each weight in the direction that would reduce the error.
  6. Repeat for many epochs. The perceptron rule is guaranteed to converge if the data is linearly separable.

The model

z = Σ wi xi + b      y = 1 if z ≥ 0, else 0

What this means: z is the evidence for class 1. The step function turns that evidence into a hard 0 or 1. The bias b shifts the cut-off, so the boundary does not have to pass through the origin.

Diagram

x1 o ---- w1 ----\ \ x2 o ---- w2 -------[ Σ + b ]----[ step ]----> y (0/1) / x3 o ---- w3 ----/ bias = 1 ---- w0 ----/

What this means: each input has its own weight. The circle with Σ adds the weighted inputs and the bias; the step block makes the final 0/1 decision.

Learning rule

For each training sample, if the output is wrong:

wi ← wi + η (t − y) xi
b ← b + η (t − y)

Here t = target, y = actual output, and η = learning rate. If the prediction is correct, no update is made.

What this means: (t − y) is 0 when correct, +1 when the target is 1 but the output is 0, and −1 when the target is 0 but the output is 1. The update pushes each weight in the direction that would fix the mistake.

Example — AND gate

With weights w1 = w2 = 1 and bias = −1.5:

x1x2z = x1 + x2 − 1.5y
00−1.50
01−0.50
10−0.50
110.51

What this means: both inputs must be 1 to push the total above zero. One input alone gives −0.5, which the step function turns into 0. This is exactly the AND truth table.

Limitations

  • Only linearly separable problems; it cannot solve XOR.
  • The step function is not differentiable, so it cannot use gradient descent.
  • No hidden layer, so it cannot learn intermediate features.
  • Sensitive to initial weights and learning rate.

The XOR limitation is why we need multilayer networks and backpropagation.

Real-life analogy: a judge scores a candidate. Each qualification gets a weight: experience counts a lot, a hobby counts a little. The judge adds the scores and adds a fixed bonus for a strong interview. If the total passes a threshold, the candidate is hired. When the judge makes a wrong call, the weights are adjusted for next time.
Common confusion: the perceptron is the model; the perceptron learning rule is the training method. The step function makes the model non-differentiable, which is why the perceptron rule is not gradient descent. And a perceptron can learn AND, OR and NOT, but not XOR, because XOR is not linearly separable.

Q2Obtain the output of neuron Y for the network shown in the figure using the activation function: (i) Binary sigmoidal (ii) Bipolar sigmoidal.

6 marks★ 1×

Asked in: 2022 Nov Q7(b) [6]

In simple words: A neuron multiplies each input by a weight, adds a bias, and applies an activation.
This question gives you the numbers and asks for two outputs: binary sigmoid and bipolar sigmoid.
The method is the same; only the finishing formula changes.

Why we do this

This is a standard exam numerical. It tests whether you can read a network diagram, compute a weighted sum, and apply the two sigmoid formulas without mixing them up. The arithmetic is simple, but the marks are in showing every step.

Words you need first

  • Net input — the weighted sum of inputs plus the bias, before the activation function.
  • Weight — the importance multiplier on one connection.
  • Bias — a constant input, usually 1, with its own weight; it shifts the net input.
  • Binary sigmoid — 1/(1+e−net), which outputs values between 0 and 1.
  • Bipolar sigmoid — (1−e−net)/(1+e−net), which outputs values between −1 and 1.
  • e — Euler’s number, about 2.718; it appears in exponential functions.
  • Activation function — the function that turns the net input into the neuron’s output.

Step-by-step

  1. Read the figure and list the values. Write x1, x2, x3, their weights, and the bias weight. State your reading clearly.
  2. Compute the net input. Multiply each input by its weight, add the bias term, and sum.
  3. Apply the binary sigmoid. Substitute net into 1/(1+e−net) and round carefully.
  4. Apply the bipolar sigmoid. Substitute the same net into (1−e−net)/(1+e−net).
  5. Check the shortcut. Bipolar = 2 × binary − 1. If the two answers disagree, you made an arithmetic slip.
  6. Report both outputs in a table. Label the activation and the formula used.

Given network

x1 = 0.8 ---- w1 = 0.1 ----\ \ x2 = 0.6 ---- w2 = 0.3 -------[ Σ ]---- f(net) ----> Y / x3 = 0.4 ---- w3 = -0.2 ----/ \ bias = 1.0 ---- w0 = 0.35 ----/

The scanned figure is handwritten over a watermark. The standard reading is x1 = 0.8, x2 = 0.6, x3 = 0.4, w1 = 0.1, w2 = 0.3, w3 = −0.2, bias = 1.0 with weight 0.35. If your copy reads x2 = 0.9 and w2 = 0.2, the product is still 0.9×0.2 = 0.18, so the net input does not change. A note at the end covers the other reading x3 = 0.2.

Step 1 — net input

net = Σ wixi + w0·bias
net = (0.1×0.8) + (0.3×0.6) + (−0.2×0.4) + (0.35×1.0)
net = 0.08 + 0.18 − 0.08 + 0.35 = 0.53

What this means: the three input-weight products are 0.08, 0.18 and −0.08. The bias adds 0.35. The negatives and positives nearly cancel, leaving a small positive net input of 0.53.

Step 2 — binary sigmoidal output

f(net) = 1 / (1 + e−net)
f(0.53) = 1 / (1 + e−0.53)
e−0.53 = 0.5886
f(0.53) = 1 / 1.5886 = 0.6295

What this means: e−0.53 is about 0.5886. The denominator becomes 1.5886, and 1 divided by that is 0.6295. The answer lies between 0 and 1, as a binary sigmoid must.

Step 3 — bipolar sigmoidal output

f(net) = (1 − e−net) / (1 + e−net)
f(0.53) = (1 − 0.5886) / (1 + 0.5886) = 0.4114 / 1.5886 = 0.2590

Equivalently, bipolar sigmoid = 2 × binary sigmoid − 1 = 2(0.6295) − 1 = 0.2590.

Q3Write a note on single-layer neural networks.

4 marks★ 1×

Asked in: 2023 Nov Q7(a) [4]

In simple words: A single-layer network has inputs connected straight to outputs.
There is no hidden layer in between. Each output is a weighted sum plus an activation.
It can solve simple straight-line problems, but not XOR.

Why we do this

The single-layer network is the simplest complete network and the base case for deeper models. It is also the output layer of almost every larger network, so understanding it helps you read bigger architectures.

Words you need first

  • Single-layer network — a network with an input layer and an output layer, but no hidden layer.
  • Input layer — the neurons that receive the raw features; they usually do no computation.
  • Output layer — the neurons that produce the final prediction.
  • Linearly separable — a problem that one straight line or plane can separate correctly.
  • Delta rule (LMS) — a learning rule that updates weights in proportion to the error.
  • Activation function — the function applied to the weighted sum.
  • Perceptron rule — update weights only when the prediction is wrong.
  • Weight — a learnable strength on a connection.
  • Bias — a constant added to the weighted sum.

Step-by-step

  1. Feed the inputs. Each input goes directly to every output neuron.
  2. Compute the weighted sum. Multiply each input by its weight and add the bias.
  3. Apply the activation. A step function gives 0/1; a sigmoid gives a probability-like value.
  4. Compare with the target. Measure the error for each output.
  5. Update the weights. Use the perceptron rule or the delta rule, then repeat.

Structure

x1 o ----\ x2 o ------> [ output neuron ] ----> y x3 o ----/ (weights on each arrow)

What this means: the arrows carry weights, but there are no intermediate neurons. The output neuron sees the inputs directly. “Single layer” counts the output layer, not the input layer.

Properties

  • Computes a linear combination followed by an activation.
  • Can solve linearly separable problems such as AND, OR and NOT.
  • Trained by the perceptron rule or the delta rule (LMS).
  • Fast and simple, but cannot solve XOR or learn complex patterns.

Use

Binary classification with a linear boundary, simple logic gates, and the output layer of a larger network.

Real-life analogy: a single judge hears the evidence directly and makes the final call. There are no junior judges or appeal committees in between. This is fast for simple cases, but the judge cannot combine low-level clues into a complex verdict.
Common confusion: “single-layer” does not mean “no weights”. It means “no hidden layer”. The input layer is not counted, because it does not compute anything. And a single-layer network can still use a non-linear activation; the limitation is the missing hidden layer, not the activation itself.

6.3 Backpropagation learning

Backpropagation = forward pass to compute the error + backward pass to distribute the error gradient + gradient-descent weight update.

Q1Write a short note on the backpropagation network. Describe the characteristics of the backpropagation algorithm.

6 marks★★ 2×

Asked in: 2022 Nov Q7(c) [6] · 2023 May Q7(b) [6 — characteristics]

In simple words: Backpropagation is how a multilayer network learns from its mistakes.
It makes a forward guess, measures the error, then sends the blame backward through every layer.
Each weight is nudged in the direction that should reduce the error.

Why we do this

Hidden neurons have no target value in the data, so we cannot tell them directly “you should have been 0.7”. Backpropagation solves this credit-assignment problem with the chain rule. It is the standard training algorithm for multilayer networks.

Words you need first

  • Backpropagation — backward propagation of errors; a gradient-based training algorithm for multilayer networks.
  • Chain rule — a calculus rule for differentiating nested functions, used to pass blame through layers.
  • Gradient — the direction and steepness of change of the loss with respect to a weight.
  • Delta (δ) — the error term at a neuron, including the activation derivative.
  • Epoch — one full pass over the training data.
  • Learning rate (η) — the step size for each weight update.
  • Local minimum — a dip in the loss that is not the lowest possible dip.
  • Convergence — the point where the loss stops improving.
  • Credit assignment — deciding which weight deserves blame for the final error.
  • MSE / cross-entropy — common loss functions for regression and classification.
  • Non-convex loss — a loss landscape with multiple dips, so training can get stuck.
  • Forward pass — computing the output from input to output.
  • Hidden neuron — a neuron in a hidden layer, with no target in the data.

Step-by-step

  1. Forward pass. Feed the input, compute activations layer by layer, and get the output.
  2. Compute the error. Compare the output with the target using MSE or cross-entropy.
  3. Output delta. Multiply the output error by the derivative of the output activation.
  4. Hidden deltas. For each hidden neuron, sum the deltas of the neurons it feeds, weighted by the connection weights, then multiply by its own activation derivative.
  5. Update weights. Move each weight by η × delta × input.
  6. Repeat. One full pass is an epoch; train until the loss converges or validation stops improving.

Three stages

  1. Forward pass — feed the input, compute activations layer by layer, get the output.
  2. Error computation — compare output with target using a loss (MSE or cross-entropy).
  3. Backward pass — propagate the error gradient from output to input and update weights.

Key equations

Output delta:  δo = (t − y) · f′(neto)
Hidden delta:  δh = f′(neth) · Σk whk δk
Weight update:  wij ← wij + η δj xi
Bias update:  bj ← bj + η δj

What this means: the output delta uses the plain error (t − y) times the activation slope. The hidden delta collects blame from every neuron ahead of it, weighted by whk, then multiplies by its own slope. The update moves each weight in proportion to its delta and its input.

Characteristics

  • Supervised — needs input–target pairs.
  • Gradient-based — uses the derivative of the activation function; it needs differentiable activations such as sigmoid, tanh or ReLU.
  • Chain rule — the error is propagated backward layer by layer.
  • Iterative — one full pass over the training data is an epoch; training repeats until convergence.
  • Local minima — can get stuck in a local minimum because the loss is non-convex.
  • Learning-rate sensitive — too high diverges, too low is slow.
  • Credit assignment — it solves the problem of assigning error blame to hidden neurons.
  • Convergence — slower than the perceptron rule but much more powerful.

Advantages and disadvantages

AdvantagesDisadvantages
Trains multilayer networksSlow convergence
Generalises to unseen dataCan stuck in local minima
Works with many activation/loss functionsNeeds careful learning-rate tuning
Efficient gradient computationCan overfit; needs regularization

What this means: backpropagation makes multilayer training possible and computes gradients efficiently, but it is not magic. It can converge slowly, get stuck, overfit, or blow up if the learning rate is wrong.

Real-life analogy: a group project gets a bad grade. The manager does not just blame the final presenter; they trace the mistake back through the slides, the analysis and the data collection. Each person gets feedback in proportion to how much they contributed to the error, and everyone adjusts for the next project.
Common confusion: backpropagation is not a type of network; it is a training algorithm. A feed-forward network can be trained by backpropagation. An epoch is one full pass, not one weight update. And gradient descent is the update rule that uses the gradients backpropagation computes; the two are partners, not synonyms.

Q2Explain the concept of backpropagation in ANN with an example.

8 marks★ 1×

Asked in: 2023 Nov Q8(a) [8]

In simple words: Follow the numbers forward to get a prediction.
Compare the prediction with the target to get the error. Send that error backward to compute each weight’s blame.
Nudge the weights and check that the error falls.

Why we do this

This numerical shows the whole backpropagation cycle on a tiny network. The arithmetic is manageable, and the pattern scales to bigger networks. If you can do this 2-2-1 example, you can answer the 8-mark “with example” question.

Words you need first

  • Forward pass — computing the output from input to output.
  • Delta (δ) — the error term at a neuron, including the activation derivative.
  • Sigmoid derivative — for σ(x), the derivative is σ(x)(1−σ(x)).
  • Learning rate (η) — the step size for each weight update.
  • Bias — a constant added to a neuron; here it is 0 for all neurons.
  • Epoch — one full pass over the training data.
  • Backward pass — sending the error gradient from output to input.
  • Weight — a learnable strength on a connection.
  • Sigmoid — σ(x) = 1/(1+e−x), a smooth 0–1 activation.
  • Hidden neuron — a neuron in the hidden layer; its target is not given.

Step-by-step

  1. Compute the hidden outputs. Use the sigmoid on each hidden net input.
  2. Compute the output and the error. Apply the sigmoid again and use ½(t−y)².
  3. Compute the output delta. Multiply (t−y) by y(1−y).
  4. Compute each hidden delta. Take the output delta, multiply by the connecting weight, then by h(1−h).
  5. Update the weights. Add η × delta × input to each weight.
  6. Recompute the output. Check that the new error is smaller than the old one.

Network used

2 inputs → 2 hidden neurons → 1 output. All neurons use the sigmoid function. Initial weights:

ConnectionWeight
x1 → h10.5
x2 → h10.4
x1 → h2−0.3
x2 → h20.2
h1 → y0.6
h2 → y−0.5

Bias = 0 for all neurons. Input x = (1, 0), target t = 1, learning rate η = 0.5.

Step 1 — forward pass

neth1 = 0.5×1 + 0.4×0 = 0.5  →  h1 = σ(0.5) = 1/(1+e−0.5) = 0.6225
neth2 = −0.3×1 + 0.2×0 = −0.3  →  h2 = σ(−0.3) = 0.4256
nety = 0.6×0.6225 + (−0.5)×0.4256 = 0.3735 − 0.2128 = 0.1607
y = σ(0.1607) = 0.5401

Error = ½(t − y)² = ½(1 − 0.5401)² = 0.1058.

What this means: h1 receives 0.5 and outputs 0.6225. h2 receives −0.3 and outputs 0.4256. The output neuron combines them into 0.5401, which is below the target 1, so the error is positive.

Step 2 — output delta

δo = (t − y) · y(1 − y)
δo = (1 − 0.5401) × 0.5401 × 0.4599 = 0.1142

What this means: (t−y) is the raw error. y(1−y) is the sigmoid slope at the output. Multiplying them gives the blame that will be sent backward.

Step 3 — hidden deltas

δh1 = δo · wh1→y · h1(1 − h1)
= 0.1142 × 0.6 × 0.6225 × 0.3775 = 0.0161

δh2 = 0.1142 × (−0.5) × 0.4256 × 0.5744 = −0.0140

What this means: h1 gets 0.6 of the output blame, so its delta is positive. h2 gets −0.5 of the blame, so its delta is negative. Each is then scaled by that hidden neuron’s own sigmoid slope.

Weights from x2 do not change because x2 = 0. This is a property of backpropagation: a zero input contributes zero gradient.

What this means: the update size is learning rate × delta × input. A larger delta or a larger input produces a larger change. A zero input switches the update off completely.

new h1 = σ(0.5081) = 0.6244, new h2 = σ(−0.3070) = 0.4239

What this means: one pass made a small improvement. Training is many such passes. The direction was right, but a single step is not convergence.

Real-life analogy: a student gets 54 out of 100 instead of the target 100. The teacher works out how much each step of the solution contributed to the lost marks, then tells the student to adjust the steps with the biggest blame. After one correction, the score rises to 55. Repeating the feedback loop gradually improves the score.
Common confusion: the delta is not the same as the raw error; it includes the activation slope. A weight with input 0 does not change, even if its delta is non-zero, because the update is multiplied by the input. And one forward-backward pass is not “training complete”; it is one step in a long loop.

Q3Compare the backpropagation network with the feed-forward network.

In simple words: A feed-forward network is an architecture: data flows one way.
Backpropagation is a training method: error flows backward to adjust the weights.
They are not opposites. The same network can be feed-forward and trained by backpropagation.

Why we do this

Students often treat these as two different networks. They are different categories: one describes the wiring, the other describes how learning happens. A clear comparison prevents a common exam mistake and shows that you understand both terms.

Words you need first

  • Feed-forward network — a network where connections go only from input toward output, with no loop.
  • Backpropagation network — a network trained by backpropagation; the phrase describes the training method, not the wiring.
  • Inference — using a trained network to make a prediction.
  • Gradient descent — the weight-update rule that uses the gradients computed by backpropagation.
  • Differentiable activation — an activation with a derivative, needed for backpropagation.
  • Architecture — the arrangement of layers and connections in a network.
  • MLP — multilayer perceptron; a fully connected network with hidden layers.
  • RNN — recurrent neural network; a network with a memory loop.

Step-by-step

  1. Describe the direction of data. Feed-forward: input → hidden → output, one way.
  2. Describe the direction of learning. Backpropagation: error travels from output back to input.
  3. Compare the role of hidden weights. In a plain feed-forward description, they are just connections; backpropagation gives them a way to learn.
  4. Compare the activation requirement. Feed-forward can use any activation; backpropagation needs a differentiable one.
  5. Compare the use. Feed-forward describes prediction; backpropagation describes training.
  6. Conclude. A trained MLP during prediction is feed-forward; the same MLP during training uses backpropagation.

6.4 FLANN and RBF networks

Q2Explain Radial Basis Function (RBF) networks in detail. Explain the building blocks of RBF networks.

6–8 marks★★★ 3×

Asked in: 2023 Nov Q7(b) [8] · 2024 May Q8(a) [6 — building blocks] · 2025 Nov Q7(c) [6 — building blocks]

In simple words: An RBF network has three layers: input, a layer of “bumps”, and a linear output.
Each bump is strongest near its own centre and fades with distance.
The output is a weighted sum of those bumps. It is a local approximator.

Why we do this

Sometimes a function is better learned piece by piece. Each RBF unit specialises in one region of the input space, like a local expert. Training is also faster than a full MLP because only the output weights need supervised learning; the hidden layer can be set by clustering.

Words you need first

  • Radial basis function (RBF) — a function whose value depends only on distance from a centre, usually a Gaussian bump.
  • Centre (cj) — the point in input space where a hidden unit responds most strongly.
  • Width (σj) — how far a unit’s influence reaches before it fades.
  • Gaussian — a smooth bell-shaped curve that peaks at its centre.
  • Local approximation — building a function from many small local pieces rather than one global rule.
  • Linear output layer — an output that is a weighted sum of hidden values, with no non-linearity.
  • Least squares — a method that chooses weights to minimise squared error.
  • Prototype — a representative point; here, the centre of an RBF unit.
  • k-means — a clustering method that groups points around K centres.
  • Delta rule — a simple weight update that moves in proportion to the error.
  • Backpropagation — the chain-rule training method for multilayer networks.
  • Interpolation — estimating values between known data points.
  • MLP — multilayer perceptron; a fully connected network with hidden layers.

Step-by-step

  1. Choose the number of hidden units m. Each unit will own one centre.
  2. Find the centres. Run k-means on the input data and use the cluster centres, or pick m points at random.
  3. Choose the widths. A common choice is the average distance to the nearest few centres. A small width makes a narrow bump; a large width makes a wide one.
  4. Compute the hidden activations. For each input, calculate how far it is from every centre and apply the Gaussian.
  5. Train the output weights. The hidden layer is fixed, so the output is linear in the weights. Solve a least-squares problem or use the delta rule.
  6. Predict. For a new input, compute the bumps and combine them with the learned output weights.

Architecture

INPUT RBF HIDDEN LAYER LINEAR OUTPUT x1 o -------- φ1(x) = exp(-||x-c1||² / 2σ1²) ----\ \ / \ x2 o ---- φ2(x) = exp(-||x-c2||² / 2σ2²) --------- o ----> y = Σ wj φj(x) + b \ / / x3 o -- φ3(x) = exp(-||x-c3||² / 2σ3²) ---------/ (each unit has a centre cj and width σj)

What this means: each hidden unit has its own centre cj and width σj. The output adds the bumps with weights wj. Only the output weights are trained by supervised learning; the centres and widths are set separately.

Building blocks

Input layerReceives the feature vector x
RBF hidden unitsCompute φj(x); each is a Gaussian “bump” centred at cj
Centres cjPositions in input space where the unit is most active; found by k-means or random selection

What this means: the centres decide where each unit looks, the widths decide how broadly it looks, and the output weights decide how much each unit contributes.

The Gaussian RBF

φj(x) = exp( − ‖x − cj‖² / (2σj²) )
y(x) = Σj=1..m wj φj(x) + b

φ is 1 at the centre and falls smoothly to 0 far away. The output is a weighted sum of bumps.

What this means: the numerator measures squared distance from x to the centre. When x = cj, the exponent is 0 and φ = 1. As distance grows, the exponent becomes more negative and φ shrinks toward 0.

Example

For a 1-D input, two centres c1 = 2, c2 = 8 with σ = 1. An input x = 2.5 gives φ1 = exp(−0.25/2) = 0.882, φ2 = exp(−30.25/2) ≈ 0. The output is almost entirely determined by the first unit. This is why RBF networks are called local approximators.

What this means: an MLP uses global sigmoid/ReLU units and trains everything by backpropagation. An RBF uses local bumps, sets the hidden layer by clustering, and trains only a linear output. RBF is faster to train but needs many units in high dimensions.

Real-life analogy: streetlights placed along a road. Each light is brightest directly underneath and fades with distance. A point on the road is lit mainly by the nearest lamp, with a little light from the next one. The output is the combined brightness of all lamps.
Common confusion: an RBF network is not just an MLP with a Gaussian activation. The hidden layer is usually set by clustering and then frozen, and the output layer is linear. The centres are not class labels; they are positions in input space. And “local” does not mean the network can only see one point; the bumps overlap.

Q1What is a Functional Link Artificial Neural Network (FLANN)? Explain its merits over other ANNs.

5 marks★ 1×

Asked in: 2023 Nov Q8(b) [5]

In simple words: FLANN expands the inputs with extra non-linear columns, such as sin, cos, products and squares.
Then it learns with a single linear layer and no hidden layer.
The expansion gives it curve-fitting power while keeping training fast and simple.

Why we do this

A plain perceptron can only draw a straight boundary. A multilayer network can draw curves but needs backpropagation and careful training. FLANN takes a middle path: it creates non-linear features by hand, then uses a simple linear learner. That makes it fast and easy to analyse.

Words you need first

  • Functional expansion — replacing the original inputs with extra functions of those inputs, such as sin(x), x² or x1x2.
  • Basis function — one of the extra functions used in the expansion.
  • Single-layer perceptron — a linear weighted sum followed by an activation, with no hidden layer.
  • Delta rule / LMS — a simple gradient-based weight update for a linear unit.
  • Convex loss — a loss with one global minimum, so training does not get trapped in a local dip.
  • Overfitting — fitting the training data too closely and failing on new data.
  • Hyperparameter — a setting chosen before training, such as the expansion order or learning rate.
  • Backpropagation — the chain-rule training method for multilayer networks.
  • System identification — building a model of a system from its input–output data.
  • Expansion order — how many and how complex the added basis terms are.

Step-by-step

  1. Start with the input vector x. For two inputs, x = [x1, x2].
  2. Expand it. Add non-linear terms such as sin(πx1), cos(πx1), sin(πx2), cos(πx2), x1x2, x1² and x2².
  3. Feed the expanded vector to a single linear layer. Each expanded term gets a weight.
  4. Train with the delta rule or LMS. Because the model is linear in the expanded features, the loss is convex and training is fast.
  5. Predict. Apply the same expansion to new inputs, then use the learned weights.

The expansion

Input: x = [x1, x2]
Expansion: [x1, x2, sin(πx1), cos(πx1), sin(πx2), cos(πx2), x1x2, x1², x2², …]
Output: y = f( Σ wj φj(x) + b )

What this means: the original two inputs become a longer vector. The extra terms are fixed functions, not learned. The output is still a weighted sum, but now it is a weighted sum of curved ingredients.

Architecture

x1 ----> [ functional expansion ] ----> φ1, φ2, ..., φm ----> [ single-layer ] ----> y x2 ----> (sin, cos, products, powers) perceptron (weights w) No hidden layer: the expansion does the non-linear mapping.

What this means: the expansion block does the non-linear work. The perceptron after it is linear and has no hidden layer. “No hidden layer” is true, but the model can still fit curves because the inputs were expanded.

Why it works

A linear perceptron can only draw a straight boundary. By adding non-linear terms such as sin, cos and products, the same linear learner can separate a non-linear region in the original space. The expansion raises the dimension; the learning stays linear and fast.

Merits over other ANNs

  • No hidden layer → much fewer weights and faster training.
  • Simple learning — the delta rule / LMS converges quickly; no backpropagation.
  • Less computational cost than an MLP with similar approximation power for many problems.
  • No local-minima problem for the single-layer case, because the loss is convex.
  • Good for non-linear system identification, function approximation and signal processing.
  • Fewer hyperparameters — mainly the expansion order and learning rate.

Limitations

  • The expansion must be chosen by hand; too many terms cause overfitting.
  • Not as flexible as a deep network for complex image or text tasks.
  • Memory grows with the number of expansion terms.
Real-life analogy: a judge can only draw a straight line through the evidence. You give the judge extra columns: “age squared”, “income × age”, and “sin of month”. In this larger table, a straight-line rule can separate a curved pattern. The judge did not get smarter; the table got richer.
Common confusion: FLANN has no hidden layer, but it is not a plain linear model on the original inputs. The expansion is fixed by the designer, not learned by backpropagation. And “no local minima” applies to the single-layer convex case; adding a huge expansion can still overfit.

6.5 Activation functions

The activation function decides whether a neuron fires and adds the non-linearity that makes deep learning possible.

Q1What is an activation function? Explain with a suitable example. Discuss any two activation functions with example.

4–5 marks★★ 2×

Asked in: 2023 May Q8(c) [5 — two functions] · 2023 Nov Q8(c) [4 — definition + example]

In simple words: An activation function decides how strongly a neuron responds.
It takes the weighted sum and bends it into an output, such as 0 to 1 or −1 to 1.
Without it, a deep network would collapse into one plain linear model.

Why we do this

Real data rarely follows a straight line. The activation adds the non-linearity that lets a network learn curves, thresholds and probabilities. It also makes the output usable: a sigmoid can be read as a probability, while a tanh keeps values centred around zero.

Words you need first

  • Activation function — a function applied to a neuron’s weighted sum to produce its output.
  • Weighted sum — the total of inputs multiplied by their weights, plus bias.
  • Non-linearity — a bend or threshold that a straight-line function cannot produce.
  • Binary sigmoid — a smooth S-shaped function with output between 0 and 1.
  • Bipolar sigmoid (tanh) — a smooth S-shaped function with output between −1 and 1.
  • Differentiable — has a derivative, so gradient-based training can use it.
  • Saturation — the flat region at the ends of a sigmoid, where the gradient is almost zero.
  • Vanishing gradient — gradients become tiny when many saturated units are stacked.
  • Probability — a number between 0 and 1 that says how likely a class is.
  • Bias — a constant added to the weighted sum before the activation.
  • Derivative — the slope of a function; backpropagation needs it.
  • Class — one of the possible labels in a classification problem.

Step-by-step

  1. Compute the weighted sum. Multiply inputs by weights and add the bias.
  2. Apply the activation. Feed the sum into the chosen function, such as sigmoid or tanh.
  3. Use the output. The next layer receives it, or the final layer turns it into a prediction.
  4. Train with the derivative. Backpropagation multiplies by the activation’s derivative to update the weights.
  5. Watch for saturation. If the output sits at the flat end, the gradient is tiny and learning slows.

Definition

An activation function is a mathematical function applied to the weighted sum of a neuron. It decides the neuron’s output and introduces non-linearity.

y = f( Σ wixi + b )

What this means: f is the activation. The neuron first computes the weighted sum plus bias, then f turns that number into the final response.

(i) Binary sigmoid

f(x) = 1 / (1 + e−x)     range (0, 1)
  • Smooth S-shape; differentiable everywhere.
  • Output can be read as a probability.
  • Used in binary classification output layers.
  • Problem: vanishing gradient for very large |x|.

Example: x = 0 → f = 0.5; x = 2 → f = 0.881; x = −2 → f = 0.119.

What this means: large positive inputs push the output toward 1; large negative inputs push it toward 0. Near 0, the curve is steep, so the neuron learns quickly. At the extremes, the curve is flat, so learning slows.

(ii) Bipolar sigmoid (tanh)

f(x) = (1 − e−x) / (1 + e−x) = tanh(x/2)    range (−1, 1)
  • Zero-centred, so gradient updates are better conditioned than with sigmoid.
  • Used in hidden layers of MLPs and RNNs.
  • Still saturates at the extremes.

Example: x = 0 → 0; x = 2 → 0.762; x = −2 → −0.762.

What this means: the output is symmetric around 0. That makes the next layer’s job easier, because positive and negative evidence are balanced. The cost is the same saturation problem at the ends.

What this means: pick the activation by the job. Step is for the classic perceptron; identity is for regression output; ReLU is the default for deep hidden layers; softmax is for multiclass probabilities.

Real-life analogy: a dimmer switch. The weighted sum is how far you turn the knob; the activation decides how the light responds. A step switch is either fully on or fully off. A sigmoid dimmer rises smoothly and then flattens at the top. Tanh is a dimmer that can also go negative.
Common confusion: the activation is not the loss function. The activation shapes each neuron’s output; the loss measures the final error. A sigmoid output is not automatically a well-calibrated probability, and sigmoid and tanh have different ranges. Also, a network with no activation is still linear no matter how many layers you stack.

Q3Write a short note on the importance of activation functions in neural networks. What is the role of activation functions, and why are they necessary for learning?

5–6 marks★★ 2×

Asked in: 2025 May Q7(a) [5] · 2025 Nov Q8(c) [6]

In simple words: Activation functions add the bends that let a network learn complex patterns.
They also decide when a neuron fires, keep outputs in a useful range, and provide the gradients needed for training.
Without them, a deep network is just one linear model.

Why we do this

Stacking linear layers does not create a more powerful model: the composition of linear functions is still linear. Activation functions break that collapse. They also make probabilities possible and let backpropagation compute useful weight updates.

Words you need first

  • Linear function — a function whose graph is a straight line; stacking them still gives a straight line.
  • Non-linearity — a bend or threshold that a straight line cannot produce.
  • Saturation — the flat part of a curve where the output barely changes and the gradient is near zero.
  • Dead ReLU — a ReLU unit that always receives negative input, so it always outputs zero and stops learning.
  • Gradient — the direction and steepness of change of the loss with respect to a weight.
  • Sparse activation — many neurons output zero, so only a few are active at a time.
  • Convergence — the point where training stops improving.
  • Bounded output — an output restricted to a fixed range, such as 0 to 1.
  • ReLU — max(0, x); the default activation for deep hidden layers.
  • Sigmoid / tanh — smooth S-shaped activations with bounded outputs.
  • Softmax — turns scores into probabilities that sum to 1.
  • Identity — f(x) = x; used for regression output.
  • Derivative — the slope of a function; it appears in every gradient.

Step-by-step

  1. Add non-linearity. Apply an activation after every hidden weighted sum. This lets the network bend its decision boundary.
  2. Decide firing strength. The activation converts a raw score into a response, such as “not at all”, “a little” or “strongly”.
  3. Keep outputs bounded where useful. Sigmoid and tanh keep values in a fixed range, which stabilises training.
  4. Provide a derivative. Backpropagation multiplies by f′(net); without a derivative, the weight cannot be updated by gradient descent.
  5. Encourage sparsity. ReLU outputs zero for negative inputs, so only some neurons stay active.
  6. Watch for saturation. If f′ is near zero, the weight stops learning; switch activation or adjust the architecture.

Why they are necessary

  1. Non-linearity — without an activation, stacking layers is useless: a composition of linear functions is still linear. The network could only draw a straight boundary no matter how deep it is.
  2. Decision making — the activation decides whether a neuron fires and how strongly.
  3. Bounded outputs — sigmoid and tanh keep values in a fixed range, which stabilises training and allows probability interpretation.
  4. Differentiability — sigmoid, tanh and ReLU have gradients, so backpropagation can update the weights.
  5. Feature selection — ReLU outputs zero for negative inputs, producing sparse activations.

Role in learning

The gradient of the loss with respect to a weight includes the derivative of the activation:

∂L/∂wij = δj · xi    where δj contains f′(netj)

What this means: δj carries the activation derivative f′(netj). If that derivative is zero, the whole update becomes zero. That is why a saturated sigmoid or a dead ReLU stops learning.

Choosing an activation

Hidden (RNN)tanhZero-centred, bounded state

What this means: there is no single best activation. Match it to the layer’s job: ReLU for deep hidden layers, tanh for recurrent hidden states, sigmoid for binary output, softmax for multiclass output and identity for regression.

One-line answer: activation functions inject non-linearity and differentiability. Without them, a deep network is just one linear model; with them, it can approximate complex functions and train by backpropagation.
Real-life analogy: a road with no bends can only take you in one direction. Add bends and junctions, and you can reach many destinations. The activation is the bend. Too sharp a bend at the end of the road (saturation) and traffic stops moving.
Common confusion: adding more layers without activations does not make a network deeper in any useful sense; it is still linear. ReLU is not always safe: a unit can “die” if it never receives a positive input. And a bounded output is not always desirable; regression often needs an unbounded identity output.

Q2What are the different activation functions used in neural networks?

6 marks★ 1×

Asked in: 2024 May Q7(b) [6]

In simple words: There are many activation functions, each with a different shape and range.
Some are good for hidden layers, some for probabilities, and one for plain regression.
Pick the function that matches the job of the layer.

Why we do this

The exam asks for the types, and a good answer needs more than names. Each function has a range, a derivative and a typical use. Knowing the trade-offs helps you explain why ReLU replaced sigmoid in deep networks and why softmax belongs at the multiclass output.

Words you need first

  • Identity (linear) — f(x) = x; the output is exactly the input.
  • Step (threshold) — outputs 1 above a threshold and 0 below it.
  • Sigmoid — a smooth S-curve that squashes values into 0–1.
  • Tanh — a smooth S-curve that squashes values into −1–1.
  • ReLU — “rectified linear unit”: max(0, x); negatives become zero.
  • Leaky ReLU — a ReLU that keeps a small slope for negative inputs.
  • Parametric ReLU — a leaky ReLU where the negative slope is learned.
  • Softmax — turns a vector of scores into probabilities that sum to 1.
  • Swish / GELU — smooth modern activations used in deep networks.
  • Dead ReLU — a ReLU unit stuck at zero, so it no longer learns.
  • Gradient descent — moving weights in the direction that lowers the loss.
  • Derivative — the slope of a function at a point.
  • Saturation — the flat region of a curve where the gradient is near zero.

Step-by-step

  1. Group by the layer’s job. Hidden layer, binary output, multiclass output or regression output.
  2. Pick a hidden activation. ReLU or Leaky ReLU for deep feed-forward networks; tanh for RNNs.
  3. Pick an output activation. Sigmoid for binary, softmax for multiclass, identity for regression.
  4. Check the range. Probabilities must stay in 0–1; regression may need any real value.
  5. Check the gradient. Avoid saturating functions in very deep stacks unless you have a reason.
  6. State the trade-off. Mention speed, saturation and interpretability for each choice.

1. Identity / linear

f(x) = x

No non-linearity. Used only in the output layer of a regression network. A network with only linear activations collapses to a single linear function.

2. Binary step / threshold

f(x) = 1 if x ≥ 0, else 0

The original perceptron. Not differentiable at 0, so it cannot be trained by gradient descent.

3. Sigmoid

f(x) = 1/(1+e−x)

Squashes to (0,1). Good for probabilities; suffers from vanishing gradients and is not zero-centred.

4. Tanh (bipolar sigmoid)

f(x) = tanh(x)

Squashes to (−1,1), zero-centred. Better than sigmoid for hidden layers, but it still saturates.

5. ReLU

f(x) = max(0, x)

Cheap, non-saturating for positive x, and sparse. The default for deep networks. Problem: “dead ReLU” if a unit always gets negative input.

6. Leaky ReLU / Parametric ReLU

f(x) = x if x > 0, else αx (α = 0.01)

Keeps a small gradient for negative inputs, so neurons do not die completely.

7. Softmax

f(xi) = exi / Σj exj

Converts a vector of scores into a probability distribution that sums to 1. Used in the output layer of multiclass classifiers.

What this means: each function has a job. Identity passes a value through; step makes a hard yes/no; sigmoid and tanh squash; ReLU keeps positive evidence; softmax turns a whole score vector into class probabilities.

8. Swish / GELU (modern)

Smooth variants used in deep networks; they often give slightly better accuracy than ReLU.

Real-life analogy: a toolbox. A hammer (ReLU) is the default for many jobs. A precision screwdriver (sigmoid) is for probability outputs. A adjustable wrench (Leaky ReLU) handles the cases where the hammer gets stuck. You choose the tool for the task, not because one tool is “best”.
Common confusion: softmax is not for binary classification; use sigmoid there. ReLU is not bounded above, so it is not a probability. Identity is usually only an output activation, not a hidden one. And the step function is historically important but not trainable by gradient descent because its derivative is zero almost everywhere.

6.6 Recurrent neural networks (RNN)

An RNN has a memory: the hidden state from the previous time step is fed back into the current step.

Q1What is a recurrent neural network? Explain with a suitable example. Explain RNN and its applications in brief.

5–6 marks★★★★★★ 6×

Asked in: 2022 Nov Q8(b) [6] · 2023 Nov Q7(c) [5 — applications] · 2024 May Q8(c) [6] · 2025 Nov Q7(b) [6] · related: 2023 May Q7(c) [6], 2025 May Q7(b) [6]

In simple words: An RNN is a neural network with memory.
It reads a sequence one item at a time and carries a summary of the past forward.
That summary is called the hidden state. The same weights are reused at every step.

Why we do this

In a sentence, a word’s meaning depends on the words before it. A plain feed-forward network sees one fixed input and forgets everything else. An RNN keeps a running memory, so it can handle text, speech, music and time series where order matters.

Words you need first

  • Sequence — data where order matters, such as words in a sentence or prices over days.
  • Time step — one position in the sequence, labelled t.
  • Hidden state (ht) — a compressed summary of everything the network has read so far.
  • Weight — a learnable number that controls how strongly one signal affects another.
  • Weight sharing — using the same weight matrix at every time step instead of learning a new one for each position.
  • Feed-forward network — a network where data flows in one direction and there is no memory loop.
  • BPTT — backpropagation through time: training an RNN by unrolling it across time steps and sending errors backward.
  • Vanishing gradient — the error signal becomes so small over long sequences that early steps barely learn.
  • Exploding gradient — the error signal grows too large and makes training unstable.
  • LSTM / GRU — RNN variants with gates that decide what to remember and what to forget.
  • Activation function — a non-linear function applied to a neuron’s weighted sum.
  • Bias — a constant added to a neuron’s sum; it shifts the result.
  • Gradient clipping — capping the size of a gradient so it cannot explode.
  • Seq2seq — sequence-to-sequence; a model that turns one sequence into another, such as translation.

Step-by-step

  1. Read the first input x1. Combine it with an initial hidden state, usually zeros.
  2. Update the hidden state. Apply weights and an activation to the old state and the new input. The result is h1.
  3. Produce an output if needed. A separate weight matrix turns h1 into y1.
  4. Carry h1 to the next step. At step 2, the network sees both x2 and the memory h1.
  5. Repeat to the end of the sequence. The final hidden state summarises the whole sequence.
  6. Train by unrolling the loop. BPTT treats each time step as a layer, then sends the error backward through all of them.

The two equations

ht = f( Wh ht−1 + Wx xt + bh )
yt = g( Wy ht + by )

What this means: the first line builds the new memory from the old memory (Whht−1) and the new input (Wxxt). The second line turns that memory into an output. f and g are activation functions, and b is a bias that shifts the result.

The unrolled diagram

y1 y2 y3 ^ ^ ^ | | | [h1] -------> [h2] -------> [h3] ---> ... ^ ^ ^ | | | [x1] [x2] [x3] Same weight matrices Wx, Wh, Wy at every step. The horizontal arrows are the memory (hidden state).

What this means: the loop on the left is drawn as a chain on the right. Each vertical arrow feeds an input; each horizontal arrow carries memory forward. The same Wx, Wh and Wy are used at every step, which is why an RNN can handle sequences of different lengths.

Why memory matters

In “The cat sat on the ___”, a feed-forward network sees only the current word. An RNN remembers “cat” and “sat”, so it can predict “mat”. The hidden state is a compressed summary of the past, not a full copy of every word.

Types of RNN

What this means: the shape of the input and output can change. One image can produce a caption (one-to-many); a whole review can produce one sentiment score (many-to-one); a sentence can produce another sentence (many-to-many).

Applications

  • Language modelling and text generation.
  • Machine translation (sequence-to-sequence).
  • Speech recognition.
  • Sentiment classification.
  • Time-series forecasting for stock, weather and sales.
  • Handwriting recognition and video analysis.

Training and problems

RNNs are trained by backpropagation through time (BPTT): the network is unrolled and the error is propagated backward through every time step.

  • Vanishing gradient — long sequences make gradients shrink to zero, so the network forgets long-range dependencies.
  • Exploding gradient — gradients grow without bound; use gradient clipping.
  • Slow — sequential computation cannot be fully parallelised.

Solutions: LSTM (input, forget and output gates), GRU (reset and update gates), gradient clipping and truncated BPTT.

What this means: the key difference is memory. A feed-forward network treats each input as independent. An RNN links inputs across time, so it can use context and order.

Real-life analogy: you read a detective novel one word at a time. By chapter five, you remember who the suspects are, what they said, and which clue came first. You do not re-read the whole book at every word. The hidden state is your memory of the story so far.
Common confusion: an RNN is not just “a deep feed-forward network”. The loop and the shared weights across time are the whole point. Also, an RNN is still trained with supervision when we have targets; “recurrent” describes the connection pattern, not a different learning rule. And the hidden state is a summary, not a perfect storage of every past input.

6.7 Convolutional neural networks (CNN)

A CNN learns local patterns with shared filters, then pools them and classifies with fully connected layers.

Q1Explain the Convolutional Neural Network with a suitable example. Draw and explain the CNN architecture.

6 marks★★★★★ 5×

Asked in: 2022 Nov Q8(c) [6 — convolution layer + hidden layer] · 2023 May Q7(c) [6] · 2024 May Q7(c) [6] · 2025 May Q7(c) [6 — architecture] · 2025 Nov Q8(b) [6]

In simple words: A CNN scans an image with small filters, like a magnifying glass.
Each filter learns one local pattern: an edge, a corner or a texture.
Pooling shrinks the result, and the final layers combine the patterns into a class.

Why we do this

An image has millions of pixels. A fully connected network would need millions of weights and would still struggle to recognise a cat that moved two pixels to the left. A CNN exploits local structure and reuses the same filter everywhere, so it learns with far fewer parameters.

Words you need first

  • Convolution — sliding a small filter over the input and computing a dot product at each position.
  • Filter (kernel) — a small learnable matrix, such as 3×3 or 5×5, that detects a pattern.
  • Feature map — the output grid produced by one filter; it shows where that pattern appeared.
  • Stride — how many pixels the filter moves at each step.
  • Padding — extra pixels added around the border to control the output size.
  • ReLU — an activation that keeps positive values and sets negatives to zero.
  • Pooling — shrinking a feature map by taking the max or average in small windows.
  • Flatten — turning a grid of feature maps into one long vector.
  • Fully connected layer — a standard dense layer where every input connects to every output.
  • Softmax — turns a vector of scores into probabilities that sum to 1.
  • Parameter sharing — using one filter at every position instead of learning a separate filter for each position.
  • Translation invariance — recognising the same object even when it shifts position.
  • Dot product — multiply matching entries and add them up.
  • Channel — one slice of an image or one feature map.
  • Bias — a constant added to each filter’s response.
  • MNIST — a standard dataset of handwritten digits used to test image models.

Step-by-step

  1. Start with the image. A colour image is a grid of height × width × 3 colour channels.
  2. Apply a convolution. Slide each filter over the image and compute a dot product with the patch under it. The result is a feature map.
  3. Apply ReLU. Keep positive responses and set negative ones to zero. This adds non-linearity.
  4. Pool. Shrink each feature map with a small window. This reduces computation and makes the result less sensitive to small shifts.
  5. Repeat convolution and pooling. Early layers detect edges; deeper layers detect shapes and objects.
  6. Flatten. Turn the final grids into one vector.
  7. Classify. Pass the vector through fully connected layers and a softmax to get class probabilities.

Architecture

What this means: the spatial size shrinks while the number of channels grows. The network trades “where exactly” for “what pattern”. By the end, a small grid describes high-level features, and the fully connected layer makes the decision.

Convolution example

A 3×3 filter (edge detector) slides over a 5×5 image with stride 1 and no padding. The output is 3×3:

output size = (W − F + 2P)/S + 1 = (5 − 3 + 0)/1 + 1 = 3

Each output cell is the dot product of the filter and a 3×3 patch. The same filter is reused at every position, which is parameter sharing.

What this means: the output is smaller than the input because the filter can only sit in positions where a full 3×3 patch fits. With a 5×5 image and a 3×3 filter, there are 3 possible positions horizontally and 3 vertically.

Example — digit recognition

Input 28×28 MNIST digit → conv 5×5 with 8 filters → 24×24×8 → pool 2×2 → 12×12×8 → conv 3×3 with 16 filters → 10×10×16 → pool → 5×5×16 → flatten 400 → dense 128 → softmax 10. The first layers detect edges, the deeper layers detect loops and strokes, and the classifier distinguishes 0–9.

Why CNN is better than a plain MLP for images

  • Local connectivity — a neuron sees a small patch, matching the local structure of images.
  • Parameter sharing — one filter is reused everywhere, so there are far fewer weights.
  • Translation invariance — pooling keeps the object recognisable even if it shifts.
  • Hierarchy — stacking layers builds edges → shapes → objects.

Convolution layer vs hidden layer (2022 Nov wording)

The convolution layer is a hidden layer: it produces hidden feature maps. In a CNN, “hidden layers” usually means the sequence of convolution + ReLU + pooling layers before the fully connected classifier. The convolution layer learns filters; the pooling layer reduces resolution; together they form the hidden representation.

Real-life analogy: you scan a large group photo with a small magnifying glass. One pass looks for vertical edges, another for horizontal edges, another for curves. After each pass, you note only the strongest hit in each small square, so the map gets smaller. At the end, you combine the notes to decide who is in the photo.
Common confusion: a CNN filter does not look at the whole image at once; it looks at a small patch. Pooling has no learnable weights; it is a fixed shrink operation. And a CNN is still a feed-forward network: the “convolution” changes the connection pattern, not the one-way flow of data.

Q2What are the different types of padding used in CNN?

6 marks★ 1×

Asked in: 2025 May Q8(b) [6]

In simple words: Padding adds extra pixels around the border of an image.
It stops the image from shrinking too fast and lets the filter see the edges.
Valid = no padding, same = keep the size, full = maximum overlap.

Why we do this

Every convolution makes the image a little smaller. After many layers, the image can shrink to nothing. Border pixels are also used less often than centre pixels, so information at the edge is lost. Padding solves both problems by adding a frame around the input.

Words you need first

  • Padding (P) — extra rows and columns added around the border of an input.
  • Valid padding — no padding at all; the filter only sees complete patches.
  • Same padding — padding chosen so the output has the same width and height as the input.
  • Full padding — padding so large that the filter overlaps the input at every possible position.
  • Stride (S) — how many pixels the filter moves between positions.
  • Filter size (F) — the width and height of the filter, such as 5×5.
  • Causal padding — padding only on the left, used for time series so the model cannot see the future.
  • Zero padding — filling the new border with zeros.
  • Reflection padding — filling the border by mirroring nearby values instead of using zeros.
  • Convolution — sliding a filter over an input and taking dot products.
  • Channel — one input slice, such as red, green or blue.
  • Bias — a constant added to each filter’s output.
  • VGG / ResNet — well-known deep CNN designs that use many convolution layers.

Step-by-step

  1. Note the input size W, filter size F, stride S and padding P. These four numbers decide the output size.
  2. Compute the output with the formula. Output = (W − F + 2P)/S + 1.
  3. Choose the padding type for your goal. Keep the size → same. Shrink → valid. Maximum border use → full.
  4. Apply the padding. Add zeros or another chosen value around the border.
  5. Run the convolution. The filter now has valid positions near the edge.
  6. Check the result. Confirm the output size is what the formula predicted.

Output-size formula

Output size = (W − F + 2P) / S + 1

What this means: W is the input width, F is the filter width, P is the padding on each side, and S is the stride. Padding adds 2P to the available width because it is added on both sides.

1. Valid padding (P = 0)

  • No padding; the filter only sees complete patches.
  • The output shrinks by F − 1: 32×32 with 5×5 → 28×28.
  • Simple, but loses border information.

2. Same padding

  • Pad so that the output has the same width and height as the input (for stride 1).
  • For a 5×5 filter, P = 2; for a 3×3 filter, P = 1.
  • Formula: P = (F − 1)/2 for odd F and S = 1.
  • Most common in deep CNNs such as VGG and ResNet.

3. Full padding

  • Pad by F − 1 on each side, so the filter is applied at every possible overlap.
  • The output is larger than the input: 32×32 with 5×5 → 36×36.
  • Rarely used; it keeps maximum border information.

4. Causal padding (1-D / time series)

Pad only on the left, so the output at time t depends only on past inputs. Temporal CNNs use this to avoid looking into the future.

5. Zero vs other padding values

  • Zero padding — the default; adds zeros.
  • Reflection / replication — mirror or repeat border values; reduces edge artefacts.
  • Constant padding — any chosen constant.

Comparison table

What this means: valid shrinks, same preserves and full enlarges. The table uses a 32×32 input, a 5×5 filter and stride 1, so the arithmetic is easy to check.

Parameter count example

Conv layer: 3 input channels, 8 filters of 5×5, one bias per filter:

params = (5×5×3 + 1) × 8 = 76 × 8 = 608

A fully connected layer from 32×32×3 to 28×28×8 would need millions of weights. This is the advantage of parameter sharing.

What this means: each 5×5 filter has 25 weights per input channel, plus one bias. With 3 input channels, one filter has 5×5×3 + 1 = 76 parameters. Eight filters give 608 parameters in total.

Real-life analogy: you are writing on a page and your pen keeps running off the edge. Padding is the margin you add around the page. With no margin (valid), the last words get cut. With a matching margin (same), the page stays the same size. With a huge margin (full), you can write every possible overlap, but the page grows.
Common confusion: “same padding” means the output has the same size, not the same values. Padding usually adds zeros, which are not learned weights. And full padding is not “better” than same; it simply keeps more border overlap and produces a larger output.

Q3Write a short note on the layers used in CNN: (i) Convolutional layer (ii) Pooling layer.

6 marks★ 1×

Asked in: 2025 May Q8(c) [6]

In simple words: A convolution layer slides small filters over the image to find patterns.
A pooling layer shrinks the result and keeps the strongest response in each small window.
Convolution learns; pooling only summarises.

Why we do this

Images contain local patterns: edges, corners, loops and textures. A convolution layer can detect the same pattern anywhere in the image with one small filter. Pooling then reduces the amount of data and makes the network less sensitive to tiny shifts.

Words you need first

  • Filter (kernel) — a small learnable matrix that is slid over the input.
  • Stride — the number of pixels the filter moves each step.
  • Padding — extra border pixels that control the output size.
  • Channel — one slice of the input, such as red, green or blue, or one feature map produced by a filter.
  • Feature map — the output grid from one filter; it shows where that filter fired.
  • Dot product — multiply matching entries and add them up.
  • Pooling — shrinking a feature map by summarising small windows.
  • Max pooling — keep the largest value in each window.
  • Average pooling — keep the average value in each window.
  • Global average pooling — average a whole feature map down to one number.
  • ReLU — an activation that keeps positive values and sets negatives to zero.
  • Convolution — sliding a filter over an input and taking dot products.
  • Bias — a constant added to each filter’s response.
  • Activation — a function applied after the convolution to add non-linearity.

Step-by-step

  1. Place the filter on the top-left patch. The patch has the same size as the filter.
  2. Multiply matching entries and add them. Add the bias. This is one output cell.
  3. Slide the filter by the stride. Repeat until the filter has covered the whole input. The grid of outputs is the feature map.
  4. Apply ReLU. Negative responses become zero; strong positive responses survive.
  5. Pool each small window. Max pooling keeps the strongest hit; average pooling keeps the overall level.
  6. Stack several filters. Each filter produces its own feature map, so the layer output has several channels.

(i) Convolutional layer

A set of learnable filters slides over the input. At each position it computes the dot product between the filter and the patch, producing a feature map.

output(i,j) = Σm Σn input(i+m, j+n) · filter(m,n) + bias

What this means: for output cell (i,j), multiply the input patch starting at (i,j) by the filter, add the bias, and write the result. The same filter is used at every position, which is parameter sharing.

  • Filter/kernel — a small matrix (3×3, 5×5) learned during training.
  • Stride — how many pixels the filter moves each step; larger stride → smaller output.
  • Padding — zeros around the border to control output size.
  • Channels — each filter produces one feature map; multiple filters produce multiple maps.
  • Parameter sharing — the same filter is used at all positions.
  • ReLU usually follows to add non-linearity.

Example: a 3×3 vertical-edge filter [[-1,0,1],[-1,0,1],[-1,0,1]] gives a high response where the image changes from dark to bright horizontally.

(ii) Pooling layer

Pooling reduces the spatial size of feature maps. It has no learnable weights.

TypeOperationProperty
Max poolingTake the maximum in each windowKeeps the strongest feature; most common
Average poolingTake the averageSmoother; keeps overall activation
Global average poolingAverage the whole feature map to one numberReplaces the flatten + FC layers; reduces overfitting

What this means: max pooling asks “was the pattern present anywhere in this window?” Average pooling asks “how strong was it on average?” Global average pooling turns a whole map into one number, which is useful before the classifier.

  • Window size — usually 2×2 with stride 2, which halves the size.
  • Effect — fewer parameters, less computation, and tolerance to small shifts.
  • No learning — pooling is a fixed operation.

Example

For the 2×2 window [[1,3],[2,4]], max pooling gives 4 and average pooling gives 2.5. A 4×4 feature map with 2×2 pooling becomes 2×2.

What this means: the window is summarised by one number. Max pooling keeps the strongest evidence; average pooling keeps the typical level.

Typical block

CONV → ReLU → POOL → CONV → ReLU → POOL → FLATTEN → FC → SOFTMAX

What this means: modern CNNs repeat “convolution → ReLU → pooling” to build a hierarchy of features, then flatten and classify. Some modern designs replace the final flatten + fully connected part with global average pooling.

Real-life analogy: a security guard scans a crowd with a small magnifying glass. Each pass looks for one kind of clue: a red hat, a badge, a raised hand. The guard then writes down only the strongest clue in each small section of the crowd. The written summary is the pooled feature map.
Common confusion: pooling does not learn anything; it has no weights to train. Convolution filters do learn. Also, a “channel” is not the same as a filter: one filter produces one output channel, but the input may already have several channels such as RGB. And a larger stride is not the same as pooling, although both shrink the output.

6.8 Personalized recommendation

Q1What is personalized recommendation? What is content-based recommendation?

6 marks★ 1×

Asked in: 2024 May Q8(b) [6]

In simple words: A personalized recommender predicts what one particular user will like.
A content-based recommender compares item features with the user’s own past likes.
If you enjoyed three sci-fi films, it looks for other sci-fi films with similar features.

Why we do this

Users face too many choices: thousands of films, songs or products. A recommender reduces that overload by ranking items for one person. Content-based recommendation is the simplest version because it needs only item features and the user’s own history, not the ratings of millions of other users.

Words you need first

  • Personalized recommendation — predicting items for one specific user from that user’s behaviour and preferences.
  • Content-based recommendation — recommending items whose features are similar to items the user already liked.
  • Collaborative filtering — recommending from the ratings and behaviour of many users, not from item features.
  • Item profile — a feature vector describing an item, such as genre, director and keywords.
  • User profile — a feature vector built from the items a user liked or rated highly.
  • Cosine similarity — a score that measures the angle between two vectors; 1 means same direction, 0 means unrelated.
  • Cold start — the problem of recommending when a new user or new item has little or no history.
  • Hybrid system — a recommender that combines content-based and collaborative signals.
  • Precision@K — of the top K recommendations, the fraction that are relevant.
  • NDCG — a ranking score that rewards relevant items appearing near the top.
  • Feature vector — a list of numbers that describes an item.
  • Recall@K — of all relevant items, the fraction that appear in the top K recommendations.
  • Click-through rate — the fraction of shown recommendations that users click.
  • Filter bubble — a state where a user only sees more of the same kind of content.

Step-by-step

  1. Build item profiles. Turn each movie into a vector of features: genre, director, actors, keywords.
  2. Build the user profile. Average the vectors of items the user liked, or weight them by rating.
  3. Score every unseen item. Compute cosine similarity between the user profile and each item profile.
  4. Rank the items. Sort by score and recommend the top K.
  5. Evaluate. Use precision@K, recall@K, NDCG or online measures such as click-through rate.
  6. Update the profile. As the user rates or clicks more items, rebuild the profile so recommendations stay current.

Personalized recommendation

A personalized recommendation system predicts what a specific user will like, based on the user’s past behaviour, preferences and the behaviour of similar users. The syllabus case study is a movie recommendation system.

  • Input: user profile, ratings, clicks, purchase history and item features.
  • Output: a ranked list of items the user is likely to enjoy.
  • Goal: reduce information overload and increase engagement or sales.

Content-based recommendation

It recommends items that are similar in content to items the user liked before. It builds an item profile (genre, director, keywords) and a user profile (an aggregate of liked items), then measures similarity.

similarity(user, item) = cos( user_profile , item_profile )
cos(A,B) = (A·B) / (‖A‖‖B‖)

What this means: the dot product measures how much the two vectors point in the same direction. Dividing by their lengths removes the effect of vector size, so only direction matters. A score near 1 means the item matches the user’s taste profile.

Example — movies

A user rated “Interstellar”, “Inception” and “The Martian” highly. Their profiles share sci-fi and space themes, and two of them share Christopher Nolan. A new movie with the same genre or director gets a high cosine similarity and is recommended. A comedy is not recommended because its feature vector points in a different direction.

What this means: content-based uses what an item is; collaborative uses what other people did. Content-based is strong when item features are rich but weak at surprising the user. Collaborative can surprise, but struggles with new users and new items.

Hybrid systems

Combine content-based and collaborative scores (weighted sum, stacking or switching) to overcome the weaknesses of each. Most real systems, such as Netflix, Amazon and Spotify, are hybrid.

Evaluation

  • Precision@K, recall@K, NDCG and hit rate.
  • Online: click-through rate, watch time and conversion.
  • Coverage, diversity and novelty for long-term user satisfaction.
Real-life analogy: a librarian knows you loved three space novels. When a new space novel arrives, the librarian reads its description, compares it with your taste, and hands it to you. The librarian does not need to ask what other borrowers thought; the match is based on the book’s content and your own history.
Common confusion: content-based recommendation is not collaborative filtering. Content-based compares item features with your profile; collaborative compares your behaviour with other users’ behaviour. Also, “similar” does not mean “good”: a recommender can confidently suggest more of the same and trap you in a filter bubble. And a new user with no history is a cold-start problem for both families.
