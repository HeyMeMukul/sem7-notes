5.1 K-means and optimisation of clusters

K-means partitions n points into K clusters by minimising the within-cluster sum of squares (WCSS).

Q1What is K-means clustering? Explain how it works with the essential steps and a suitable example. What are its applications?

5–8 marks★★★★★ 5×

Asked in: 2022 Nov Q5(b) [6] · 2023 Nov Q5(a) [8] · 2024 May Q6(b) [6] · 2025 May Q6(b) [6 — essential steps] · 2025 Nov Q5(a) [5 — principles + applications]

Definition

K-means is an unsupervised, partitional clustering algorithm. It divides n objects into K non-overlapping clusters so that objects in the same cluster are as similar as possible. Similarity is measured by distance from the cluster centroid (mean).

Minimise  WCSS = Σk=1..K Σx∈Ck ‖x − μk‖²

Algorithm (Lloyd’s algorithm)

1. Choose K (number of clusters).
2. Select K initial centroids (random points or k-means++).
3. Repeat:
     a. Assignment: assign each point to the nearest centroid.
     b. Update: recompute each centroid as the mean of its points.
     c. If centroids do not change (or max iterations reached), stop.
4. Return the K clusters.

Worked example — 7 points, K = 2

Data (A, B scores): 1=(1,1), 2=(1.5,2), 3=(3,4), 4=(5,7), 5=(3.5,5), 6=(4.5,5), 7=(3.5,4.5). Initial centroids: point 1 (1,1) and point 4 (5,7), the two farthest points.

Complexity

Time: O(n · K · d · I), where n = points, K = clusters, d = dimensions, I = iterations. Space: O(n + K).

Applications

  • Customer segmentation (market basket analysis).
  • Image compression / colour quantisation.
  • Document clustering and topic grouping.
  • Anomaly detection (points far from every centroid).
  • Pre-processing for supervised learning (vector quantisation).

Limitations

  • K must be chosen in advance.
  • Sensitive to initial centroids → use k-means++ or multiple restarts.
  • Assumes spherical, similar-sized clusters.
  • Sensitive to outliers (the mean is dragged).
  • Only finds a local optimum.

Q2With reference to clustering, explain the issue of “optimisation of clusters”. Write a short note on optimisation of clusters.

6–9 marks★★ 2×

Asked in: 2023 May Q5(a) [6] · 2023 Nov Q6(b)(i) [9]

What the issue means

Clustering has no labels, so “optimal” is not obvious. Optimisation of clusters means choosing the number of clusters K and the cluster assignments that best balance compactness (points close to their centroid) and separation (clusters far apart).

1. Choosing K

  • Elbow method — plot WCSS vs K; choose the knee where the fall slows down.
  • Silhouette score — choose K with the highest average silhouette.
  • Gap statistic — compare WCSS with the WCSS of random data.
  • Domain knowledge — the business may fix K (e.g. 3 customer tiers).

2. Objective function

WCSS = Σk Σx∈Ck ‖x − μk‖²

Lower WCSS is better, but WCSS always falls as K increases (at K = n it is zero). That is why we cannot simply minimise WCSS; we need a penalty or a knee.

3. Local optima and initialisation

  • K-means converges to a local minimum, not necessarily the global one.
  • Bad initial centroids can merge two real clusters or split one.
  • k-means++ chooses initial centroids far apart, which improves the result.
  • Run the algorithm several times with different seeds and keep the lowest WCSS.

4. Other optimisation issues

  • Empty clusters — reassign the farthest point or reinitialise the centroid.
  • Outliers — pull the mean; use K-medoids or remove outliers first.
  • Feature scaling — a large-range feature dominates the distance; normalise first.
  • High dimensions — distances become similar (curse of dimensionality); reduce dimensions with PCA.
  • Cluster shape — K-means assumes convex/spherical clusters; density or spectral methods may be better.
One-line answer: optimisation of clusters = choose K and the partition that minimise intra-cluster distance and maximise inter-cluster distance, while avoiding local optima caused by initialisation and outliers.

5.2 K-medoids (PAM)

Q1Why is K-medoid used? Explain the K-medoid algorithm.

5–6 marks★★★★ 4×

Asked in: 2023 May Q6(a) [6 — choosing number of clusters] · 2023 Nov Q6(b)(ii) [9] · 2024 May Q5(a) [5] · 2025 Nov Q5(b) [6]

Why K-medoids is used

K-means uses the mean as the cluster centre. The mean is not an actual data point and is badly affected by outliers. K-medoids uses an actual data point — the medoid — as the centre. The medoid is the object with the smallest average distance to all other objects in its cluster.

  • Robust to outliers — a medoid is a real point, so one extreme value cannot drag it far.
  • Works with any distance metric — Manhattan, Minkowski, even a precomputed dissimilarity matrix. K-means needs Euclidean distance to compute the mean.
  • Interpretable centre — the representative is an actual sample (e.g. a real customer profile).
  • Handles categorical / mixed data better when a suitable distance is defined.

PAM algorithm (Partitioning Around Medoids)

1. Choose K objects as initial medoids.
2. Assign each remaining object to the nearest medoid.
3. For each medoid m and each non-medoid o:
     compute the total cost S of swapping m with o
     (sum of distances from every point to its nearest medoid).
4. If S < 0, perform the swap (the clustering improves).
5. Repeat steps 2-4 until no swap improves the cost.
6. Return the K medoids and their clusters.

Cost function

Cost = Σi=1..n minm∈M d(xi, m)

PAM tries to minimise the sum of dissimilarities to the closest medoid. A swap is accepted only if the total cost decreases.

Complexity

Each iteration evaluates K(n−K) swaps, and each evaluation costs O(n). Total ≈ O(K n²) per iteration, which is more expensive than K-means (O(nKdI)).

K-means vs K-medoids

PointK-meansK-medoids
CentreMean (not a real point)Medoid (a real point)
OutliersSensitiveRobust
DistanceEuclidean (to compute mean)Any metric
ComplexityO(nKdI)O(Kn²) per iteration
Cluster shapeConvex / sphericalAny shape (distance-based)
UseLarge numeric dataNoisy data, categorical data, small n

Choosing the number of clusters in K-medoids

  • Elbow method — plot the total cost vs K and look for the knee.
  • Silhouette coefficient — choose K with the best average silhouette.
  • Domain knowledge — the number of natural groups may be known.
  • Gap statistic — compare the cost with that of a null reference dataset.
  • For PAM, the average silhouette width is the standard built-in choice.

5.3 Hierarchical clustering

Hierarchical clustering builds a tree of clusters. Agglomerative = bottom-up; divisive = top-down.

Q1Write a short note on hierarchical clustering methods: (i) Agglomerative (ii) Dendrogram. Explain hierarchical clustering with an example.

6 marks★★★★★ 5×

Asked in: 2022 Nov Q5(c) [6] · 2023 Nov Q6(a) [9] · 2024 May Q6(c) [6] · 2025 May Q5(a) [6] · 2025 Nov Q6(b) [6]

Definition

Hierarchical clustering creates a nested hierarchy of clusters. It does not need K in advance; the result is a tree called a dendrogram. Cutting the dendrogram at a chosen height gives the clusters.

(i) Agglomerative clustering (AGNES)

Bottom-up approach:

  1. Start with each point as its own cluster (n clusters).
  2. Find the two closest clusters and merge them.
  3. Repeat until one cluster remains (or the desired K is reached).

The result is a dendrogram whose merge heights show the distance at which clusters joined.

Linkage methods

AverageAverage of all pairwise distancesCompromise

WardIncrease in within-cluster varianceCompact clusters; popular

(ii) Dendrogram

A dendrogram is a tree diagram of the merges. The y-axis is the distance (or dissimilarity); the x-axis lists the objects. A horizontal cut at height h gives the clusters at that level.

Worked example — one-dimensional data [7, 10, 20, 28, 35]

5.4 Density-based, graph-based and spectral clustering

Density methods find arbitrary-shaped clusters and label sparse regions as noise. Graph/spectral methods cut a similarity graph.

Q1Explain density-based clustering with reference to DBSCAN, OPTICS and DENCLUE. Explain how a cluster is formed in the density-based clustering algorithm. Why is density-based clustering used?

6–9 marks★★★★★★ 6×

Asked in: 2022 Nov Q5(a) [6] · 2023 May Q5(c) [6] · 2023 Nov Q6(a) [9] · 2024 May Q5(b) [6] · 2025 May Q6(c)(ii) [6] · 2025 Nov Q5(c) [6 — DBSCAN terms]

Idea

A cluster is a dense region of points separated by sparse regions. Density-based methods do not need K and can find arbitrary shapes. They also identify noise instead of forcing every point into a cluster.

DBSCAN — Density-Based Spatial Clustering of Applications with Noise

Two parameters: ε (radius) and MinPts (minimum neighbours).

TermDefinition
ε-neighbourhoodNε(p) = {q ∈ D | dist(p,q) ≤ ε}
Core point|Nε(p)| ≥ MinPts
Border pointNot a core point, but lies in the ε-neighbourhood of a core point
Noise pointNeither core nor border
Directly density-reachableq ∈ Nε(p) and p is a core point
Density-reachableThere is a chain p1, …, pn where each pi+1 is directly reachable from pi
Density-connectedThere exists a point o such that both p and q are density-reachable from o

How a cluster is formed

1. Pick an unvisited point p.
2. If p is not a core point, mark it as noise (it may later become a border point).
3. If p is a core point, create a new cluster and add all points
   density-reachable from p (expand the neighbourhood recursively).
4. Repeat until every point is visited.

All points in one density-connected region end up in the same cluster. Points in sparse regions remain noise.

OPTICS — Ordering Points To Identify the Clustering Structure

  • Handles varying density, which DBSCAN struggles with (one global ε).
  • Computes a core distance and a reachability distance for each point.
  • Produces an ordered list and a reachability plot; valleys = clusters, peaks = noise.
  • You can extract clusters at different ε levels from one run.

DENCLUE — DENsity-based CLUstEring

  • Models the density with a kernel density estimate: f(x) = (1/(nhd)) Σ K((x − xi)/h).
  • Clusters are regions around density attractors (local maxima).
  • Points are assigned by hill-climbing to the nearest attractor.
  • Handles noise, arbitrary shapes and large data; but the bandwidth h and threshold are hard to choose.

Why density-based clustering is used

  • Finds arbitrary-shaped clusters (elongated, ring-shaped), unlike K-means.
  • Does not require K in advance.
  • Explicitly identifies noise and outliers.
  • Robust to outliers because they are not forced into a cluster.
  • DBSCAN is O(n log n) with a spatial index (O(n²) without).

Limitations

  • ε and MinPts are difficult to choose; results are very sensitive to them.
  • Struggles when clusters have very different densities (use OPTICS).
  • High-dimensional data makes density estimation hard.

Q2Explain graph-based clustering. Write a short note on graph-based and density-based clustering.

6 marks★★ 2×

Asked in: 2022 Nov Q6(b) [6] · 2025 May Q6(c)(i) [6]

Idea

Represent each data point as a vertex and the similarity between points as a weighted edge. Clustering becomes a graph partitioning problem: cut the graph into components with strong internal edges and weak cut edges.

Graph construction

  • ε-neighbourhood graph — connect points within distance ε.
  • k-nearest-neighbour graph — connect each point to its k nearest neighbours.
  • Fully connected graph — every pair connected; weight = similarity (e.g. Gaussian).

Partitioning

  • Minimum cut — remove edges with the smallest total weight. It may isolate a single vertex; use normalised cut to balance cluster sizes.
  • Spectral clustering — use the eigenvectors of the graph Laplacian to embed the graph in a low-dimensional space, then run K-means.
  • Chameleon — hierarchical graph clustering based on relative interconnectivity and closeness.

Example

Six points forming two triangles connected by one weak edge. A min-cut removes that weak edge and returns the two triangles as clusters, even if they are not linearly separable in the original space.

Advantages / disadvantages

AdvantagesDisadvantages
Finds non-convex clustersO(n²) or O(n³); not scalable
Uses global similarity structureNeeds a good similarity graph
Works well for image and network dataSensitive to the graph construction and parameters

Q3Explain the spectral clustering algorithm. Differentiate between K-means and spectral clustering.

5–6 marks★★ 2×

Asked in: 2023 May Q6(c) [6 — K-means vs spectral] · 2023 Nov Q5(c) [5 — spectral algorithm]

Algorithm

1. Build the affinity matrix W (e.g. W_ij = exp(-||x_i - x_j||^2 / (2*sigma^2))).
2. Compute the degree matrix D, where D_ii = sum_j W_ij.
3. Compute the graph Laplacian L = D - W
   (or the normalised Laplacian L_sym = I - D^(-1/2) W D^(-1/2)).
4. Find the k smallest eigenvectors of L.
5. Form a matrix U with those eigenvectors as columns.
6. Treat each row of U as a new point and run K-means (or another algorithm).
7. Map the cluster labels back to the original points.

Why it works

The eigenvectors of the Laplacian encode the “smoothness” of the graph. Points in the same densely connected component get similar eigenvector values, so they become close in the new space even if they were far apart in the original space.

Example — two concentric circles

K-means cuts the circles with a straight line and fails. Spectral clustering builds a similarity graph where each circle is a connected component, and the cut separates the two rings correctly.

K-means vs spectral

PointK-meansSpectral
BasisDistance to centroidGraph connectivity / eigenvectors
Cluster shapeConvex, sphericalArbitrary, non-convex
InputFeature vectorsSimilarity/affinity matrix
ComplexityO(nKdI)O(n³) for eigendecomposition
ScalabilityLarge dataSmall/medium data
ParametersKK, kernel width σ, graph type
Failure caseConcentric circles, moonsVery large graphs, bad affinity matrix

Spectral clustering is essentially graph partitioning + K-means in the eigenvector space. Mention this line; it links the two syllabus topics.

5.5 Outlier analysis

An outlier is an observation that deviates so much from the rest of the data that it looks like it was generated by a different mechanism.

Q1What is outlier analysis? Explain it with importance, advantages and disadvantages. Write a short note on outlier analysis with respect to clustering.

6 marks★★★ 3×

Asked in: 2023 May Q6(b) [6] · 2024 May Q5(c) [6] · 2025 May Q5(b) [6]

Definition

Outlier analysis is the process of detecting, explaining and handling data objects that do not follow the general pattern of the dataset. Such objects are also called anomalies.

Types of outliers

  • Point outlier — a single value far from the rest (salary = 10 crore).
  • Contextual outlier — normal in one context, abnormal in another (30 °C in summer vs winter).
  • Collective outlier — a group of values that is anomalous together (a sudden sequence of failed logins).

Why it matters

  • Data quality — outliers may be typing errors, sensor faults or missing-value codes.
  • Model damage — the mean and variance are sensitive; K-means centroids and linear regression lines get dragged.
  • Fraud / intrusion detection — the outlier is the event of interest (credit-card fraud, network attack).
  • Medical and industrial monitoring — a sudden reading can indicate a fault.

Detection methods

FamilyMethodIdea
Statisticalz-score, IQR, GrubbsValues beyond 3σ or 1.5×IQR
DistancekNN distanceFar from its neighbours
DensityLOFLower density than its neighbours
ClusteringK-means / DBSCANFar from centroid / labelled noise
IsolationIsolation forestEasily isolated by random splits
ClassificationOne-class SVMLearn the boundary of normal data

Advantages

  • Improves data quality and model accuracy.
  • Detects fraud, faults and rare events.
  • Prevents distortion of means, variances and cluster centres.
  • Can reveal a new, unknown phenomenon.

Disadvantages

  • “Outlier” is domain-dependent; a statistical outlier may be a valid rare case.
  • High-dimensional data makes distance/density unreliable.
  • Methods need thresholds/parameters that are hard to set.
  • Removing outliers can delete important information.
  • Labeled anomaly data is rare, so supervised evaluation is difficult.

Q2What is LOF? Explain it with its advantages and disadvantages. What is outlier analysis and how is Local Outlier Factor detected?

5–6 marks★★ 2×

Asked in: 2022 Nov Q6(a) [6] · 2023 Nov Q5(b) [5]

Definition

Local Outlier Factor (LOF) is a density-based anomaly detection method. It compares the local density around a point with the local densities of its neighbours. A point in a sparser region than its neighbours gets a high LOF.

Steps

  1. k-distance(p) — distance from p to its k-th nearest neighbour.
  2. k-distance neighbourhood Nk(p) — all points within that distance.
  3. Reachability distance:
    reach-distk(p, q) = max( k-distance(q), d(p, q) )
  4. Local reachability density:
    lrdk(p) = 1 / [ (1/|Nk(p)|) Σq∈Nk(p) reach-distk(p, q) ]
  5. LOF:
    LOFk(p) = [ (1/|Nk(p)|) Σq∈Nk(p) lrdk(q) ] / lrdk(p)

Interpretation

LOF valueMeaning
≈ 1Similar density to its neighbours → normal point
< 1Denser than its neighbours → inlier
> 1 (e.g. > 1.5)Sparser than its neighbours → outlier

Example

Point A sits in a dense cluster (lrd high). Point B sits alone far away (lrd low). B’s neighbours are mostly normal points with higher lrd, so the ratio (average neighbour lrd)/(B’s lrd) is large → high LOF → B is flagged.

Advantages

  • Detects local outliers, not just global ones.
  • Works when clusters have different densities.
  • No assumption about the data distribution.
  • Gives a score, not just a binary label; threshold can be tuned.

Disadvantages

  • Needs k; results depend on it.
  • O(n²) distance computations (can be indexed).
  • Not reliable in very high dimensions.
  • Sensitive to the choice of distance metric.
  • Does not work well if the outlier is in a dense but different region.

Q3What is the isolation factor model? What is the isolation forest?

5 marks★★ 2×

Asked in: 2024 May Q6(a) [5] · 2025 Nov Q6(a) [5]

Idea

The paper uses “isolation factor model”; the standard name is Isolation Forest. It is an unsupervised anomaly detector based on the fact that anomalies are few and different, so random splits isolate them in fewer steps than normal points.

How it works

  1. Build many isolation trees. Each tree repeatedly picks a random feature and a random split value between the min and max of that feature.
  2. Continue until every point is isolated (leaf) or a depth limit is reached.
  3. The path length h(x) is the number of splits needed to isolate x.
  4. Average the path length over all trees: E[h(x)].
  5. Compute the anomaly score:
    s(x, n) = 2−E[h(x)] / c(n)
    where c(n) = 2H(n−1) − 2(n−1)/n and H is the harmonic number.

Interpretation

  • Short path (isolated quickly) → s close to 1 → anomaly.
  • Long path → s close to 0.5 or below → normal.
  • Typical rule: s > 0.6 → suspicious; s > 0.75 → strong anomaly.

Example

In a set of employee salaries, one salary of ₹10 crore is separated by the first random split on “salary”, while normal salaries need many splits to separate. Its average path length is short, so its score is near 1 and it is flagged.

Advantages / disadvantages

AdvantagesDisadvantages
Fast: O(n log n) trainingStruggles with local outliers in dense regions
No distance metric neededRandom splits are less effective in high dimensions
Scales to large data; low memoryNeeds a contamination estimate / threshold
Works without labelsLess interpretable than LOF

5.6 Evaluation of clustering — elbow, intrinsic/extrinsic

Q1Write a short note on the elbow method used in K-means clustering.

6 marks★★ 2×

Asked in: 2022 Nov Q6(c)(i) [6] · 2025 May Q5(c) [6]

Purpose

The elbow method chooses the number of clusters K. It plots the within-cluster sum of squares (WCSS) against K and looks for the “elbow” where adding another cluster stops giving a big improvement.

Procedure

  1. Run K-means for K = 1, 2, 3, …, Kmax.
  2. For each K, compute WCSS = ΣkΣx∈Ck‖x − μk‖².
  3. Plot WCSS vs K.
  4. Choose the K at the bend (elbow) — after this point the curve flattens.

Typical plot

WCSS |* | * | * | * | *___ | *___*___* <- elbow at K = 4 +---------------------- K 1 2 3 4 5 6 7 8

Why it works

Before the true K, each new cluster explains a lot of variance, so WCSS falls steeply. After the true K, new clusters only split existing compact groups, so the fall is small. The change in slope marks the elbow.

Limitations

  • The elbow is not always sharp; the curve can be smooth (ambiguous).
  • WCSS always decreases with K, so it cannot be used alone.
  • Use the silhouette score or gap statistic to confirm.
  • Results depend on scaling and outliers.

Example

For the 7-point dataset in §5.1, K = 2 gives a large drop from K = 1. K = 3 gives a smaller drop, and K = 4 barely improves. The elbow is at K = 2, matching the two visible groups.

Q2Define extrinsic and intrinsic methods of measuring clustering quality. Compare intrinsic and extrinsic evaluation. (2025 May prints “intrinsic motivation with extrinsic motivation” — the syllabus topic is intrinsic vs extrinsic evaluation methods.)

6 marks★★★ 3×

Asked in: 2022 Nov Q6(c)(ii) [6] · 2025 May Q6(a) [6] · 2025 Nov Q6(c) [6]

Intrinsic (internal) methods

Evaluate the clustering using only the data and the cluster assignments. No true labels are needed. They measure compactness (points close within a cluster) and separation (clusters far apart).

  • Silhouette coefficient: s = (b − a)/max(a,b), where a = mean intra-cluster distance, b = mean distance to the nearest other cluster. Range −1 to 1; higher is better.
  • Davies–Bouldin index: average ratio of within-cluster scatter to between-cluster separation; lower is better.
  • Dunn index: minimum inter-cluster distance / maximum intra-cluster diameter; higher is better.
  • WCSS / SSE and the elbow method.

Extrinsic (external) methods

Compare the clustering with a known ground-truth partition (class labels). Used when labelled data is available.

  • Purity — fraction of points that belong to the majority class in their cluster.
  • Entropy — impurity of the classes within clusters; lower is better.
  • Adjusted Rand Index (ARI) — agreement between two partitions, corrected for chance; range ≈ −1 to 1, 1 = perfect.
  • Normalised Mutual Information (NMI) — shared information between clustering and labels; 0 to 1.
  • Homogeneity and completeness — each cluster contains one class / each class is in one cluster.
  • F-measure — harmonic mean of precision and recall of pairs.

Q3Write a short note on evaluation metrics for clustering.

9 marks★ 1×

Asked in: 2023 Nov Q6(b)(iii) [9]

1. SSE / WCSS

SSE = Σk Σx∈Ck ‖x − μk‖²

Lower is better for a fixed K. Use the elbow plot to choose K.

2. Silhouette coefficient

a(i) = average distance from i to points in its own cluster
b(i) = minimum average distance from i to points in another cluster
s(i) = (b(i) − a(i)) / max(a(i), b(i))

Range −1 to 1. s ≈ 1 → well clustered; s ≈ 0 → on a boundary; s < 0 → probably in the wrong cluster. Average over all points.

3. Davies–Bouldin index

DB = (1/K) Σi maxj≠i ( (σi + σj) / d(ci, cj) )

σ = average distance of points to their centroid. Lower DB is better (compact, well-separated).

4. Dunn index

D = mini≠j d(Ci, Cj) / maxk diam(Ck)

Higher is better: large separation, small diameter.

5. External metrics

  • Purity = (1/n) Σk maxj |Ck ∩ Lj|.
  • Entropy = −Σ (|Ck|/n) Σ pkj log pkj; lower is better.
  • ARI — pair-counting agreement corrected for chance.
  • NMI — mutual information normalised to 0–1.

SituationRecommended metric
No labels, convex clustersSilhouette, DB, Dunn
No labels, choose KElbow (SSE), silhouette
Labels availableARI, NMI, purity, entropy
Different density clustersSilhouette may fail; use visual/domain check
