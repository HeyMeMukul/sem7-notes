4.1 Evaluating classification models

Syllabus: Accuracy, Precision, Recall, F-score, confusion matrix, cross-validation, micro/macro averages.

Q1Explain in brief the methods used for evaluating classification models. Write a short note on metrics for evaluating classifier performance.

5–6 marks★★ 2×

Asked in: 2022 Nov Q3(a) [5] · 2025 May Q3(c) [6]

1. Confusion matrix

A 2×2 table for binary classification with TP, TN, FP, FN. Every other metric is computed from these four numbers.

Predicted PositivePredicted Negative
Actual PositiveTPFN
Actual NegativeFPTN

2. Accuracy

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Fraction of all predictions that are correct. Misleading when classes are imbalanced.

3. Precision

Precision = TP / (TP + FP)

Of all samples the model labelled positive, how many really are positive. Important when a false alarm is costly (spam filter).

4. Recall (Sensitivity / TPR)

Recall = TP / (TP + FN)

Of all actual positives, how many the model found. Important when missing a positive is costly (cancer detection).

5. F1-score

F1 = 2 × Precision × Recall / (Precision + Recall)

Harmonic mean of precision and recall. High only when both are high.

6. Other methods

  • Specificity / TNR = TN/(TN+FP).
  • ROC curve — TPR vs FPR at all thresholds; AUC summarises it.
  • Precision–Recall curve — better than ROC for imbalanced data.
  • Log loss / cross-entropy — punishes confident wrong probabilities.
  • Macro / micro / weighted averages for multiclass.
  • Cross-validation — estimates performance on unseen data.

Q2Explain (i) Accuracy (ii) Precision (iii) Recall and (iv) F-score.

8 marks★ 1×

Asked in: 2023 Nov Q4(b) [8]

Use the same four quantities from the confusion matrix. Write the formula, the meaning in one line, and when to use it.

MetricFormulaQuestion it answersUse when
Accuracy(TP+TN)/(TP+TN+FP+FN)How many predictions are correct overall?Classes are balanced
PrecisionTP/(TP+FP)When we say positive, how often are we right?False positives are costly
RecallTP/(TP+FN)Of the real positives, how many did we catch?False negatives are costly
F-score2PR/(P+R)Balance precision and recallBoth errors matter; imbalanced data

Worked example

TP = 40, TN = 50, FP = 10, FN = 0.

Accuracy = (40+50)/100 = 0.90
Precision = 40/50 = 0.80
Recall = 40/40 = 1.00
F1 = 2×0.8×1.0/(1.8) = 0.8889

Recall is perfect because there are no false negatives, but precision is only 0.80 because 10 negatives were wrongly flagged. F1 = 0.889 captures both facts; accuracy 0.90 alone hides the false alarms.

Accuracy paradox: with 95 negatives and 5 positives, a model that always says “negative” gets 95% accuracy but recall = 0. Always report precision/recall/F1 on imbalanced data.

Q3Write a short note on the importance of the confusion matrix.

6 marks★ 1×

Asked in: 2022 Nov Q4(b) [6]

What it is

A confusion matrix is a table that compares actual class labels with predicted labels. For two classes it has four cells: TP, TN, FP, FN.

Why it is important

  1. Shows the type of error — accuracy only says “90% correct”; the matrix says whether the 10% errors are false positives or false negatives.
  2. Base for all metrics — accuracy, precision, recall, specificity and F1 are all calculated from its four cells.
  3. Exposes class imbalance — a high-accuracy model can still have terrible recall for the minority class; the matrix makes this visible.
  4. Cost-sensitive decisions — if a false negative costs more than a false positive (medical test), the matrix shows which one dominates.
  5. Multiclass diagnosis — a 4×4 matrix shows which classes are confused with which (e.g. class A predicted as B).
  6. Threshold tuning — changing the decision threshold changes FP and FN; the matrix shows the trade-off.

Example

Model A: 90% accuracy with 0 FP and 20 FN. Model B: 90% accuracy with 20 FP and 0 FN. Accuracy is identical, but the matrices show completely different behaviour. For cancer screening, B (no missed cases) is better; for spam filtering, A may be better.

Q4A binary classifier has TP = 120, TN = 45, FP = 10, FN = 5. Calculate accuracy, precision, recall and F1-score.

6 marks★ 1×

Asked in: 2025 Nov Q3(c) [6]

Step 1 — total

Total = TP + TN + FP + FN = 120 + 45 + 10 + 5 = 180

Step 2 — metrics

Accuracy = (TP + TN)/Total = (120 + 45)/180 = 165/180 = 0.9167 = 91.67%

Precision = TP/(TP + FP) = 120/(120 + 10) = 120/130 = 0.9231 = 92.31%

Recall = TP/(TP + FN) = 120/(120 + 5) = 120/125 = 0.9600 = 96.00%

F1 = 2PR/(P + R) = 2×0.9231×0.96/(0.9231 + 0.96)
F1 = 1.7723/1.8831 = 0.9412 = 94.12%

Step 3 — interpretation

  • Accuracy 91.67% — 15 of 180 predictions are wrong (10 FP + 5 FN).
  • Precision 92.31% — when the model says positive, it is right 92% of the time.
  • Recall 96% — it catches 96% of all real positives; only 5 are missed.
  • F1 94.12% — high because both precision and recall are high.

Exam tip: write the formula first, then substitute, then the percentage. Step marks are given for the formula even if arithmetic slips.

Q6What is the relation between precision and recall? Explain with an example.

4 marks★ 1×

Asked in: 2023 Nov Q3(c) [4]

Relation

Precision and recall usually move in opposite directions when the decision threshold changes. This is the precision–recall trade-off.

  • Lower the threshold → more samples are called positive → recall rises, precision usually falls (more false positives).
  • Raise the threshold → fewer positives → precision rises, recall falls (more false negatives).
  • F1 combines both: F1 = 2PR/(P+R).

Example — cancer screening

ThresholdTPFPFNPrecisionRecall
Low (0.2)4830248/78 = 0.61548/50 = 0.960
High (0.8)3521535/37 = 0.94635/50 = 0.700

At the low threshold we catch almost all cancers (recall 96%) but many healthy people are flagged (precision 61.5%). At the high threshold precision is 94.6% but 15 cancers are missed (recall 70%). The doctor must choose the threshold based on the cost of each error.

Q7What is K-fold cross-validation? Comment on the situations when K is too large and when K is too small. How do you decide the value of K?

9 marks★ 1×

Asked in: 2023 Nov Q4(a) [9]

Definition

K-fold cross-validation splits the dataset into K equal folds. The model is trained K times; each time one fold is the test set and the other K−1 folds are the training set. The final score is the average of the K scores.

Procedure

1. Shuffle the dataset (keep class proportions if stratified).
2. Split into K folds F1, F2, ..., FK.
3. For i = 1 to K:
      train on all folds except Fi
      test on Fi
      record score Si
4. Final score = (S1 + S2 + ... + SK) / K

Diagram (K = 5)

Round 1 [ TEST ][ TRAIN ][ TRAIN ][ TRAIN ][ TRAIN ] Round 2 [ TRAIN ][ TEST ][ TRAIN ][ TRAIN ][ TRAIN ] Round 3 [ TRAIN ][ TRAIN ][ TEST ][ TRAIN ][ TRAIN ] Round 4 [ TRAIN ][ TRAIN ][ TRAIN ][ TEST ][ TRAIN ] Round 5 [ TRAIN ][ TRAIN ][ TRAIN ][ TRAIN ][ TEST ]

When K is too large

  • Each training set is almost the full dataset → the K models are very similar, so averaging adds little.
  • Training cost is K times the single-fit cost. For K = n (leave-one-out) this is extremely expensive.
  • Variance of the estimate can increase because the training sets overlap heavily.
  • Leave-one-out has low bias but high variance and is impractical for large data.

When K is too small

  • Each training set is much smaller than the full data (e.g. K = 2 uses only 50%) → the model is trained on less data, so the estimate is pessimistic (high bias).
  • Fewer folds → higher variance in the estimated score; the result depends on how the split happened.
  • Example: K = 2 is cheap but unreliable; K = 3 is the minimum for a reasonable estimate.

How to choose K

  • K = 5 or 10 is the standard compromise between bias, variance and cost.
  • Small dataset → larger K (10 or leave-one-out) to use more data for training.
  • Large dataset → K = 5 is enough; the training fraction is already ~80%.
  • Use stratified K-fold for classification so each fold has the same class ratio.
  • Use nested cross-validation when hyperparameters are tuned: inner folds for tuning, outer folds for the final estimate.
  • For time-series, use forward-chaining splits, not random K-fold.
9-mark structure: definition (2) + procedure/diagram (2) + too-large K (2) + too-small K (2) + how to choose (1).

4.2 K-nearest neighbours (KNN)

KNN is a lazy, non-parametric classifier: it stores the training data and votes among the K closest points.

Q1Discuss the K-nearest neighbour algorithm with a suitable example. Explain KNN with an example.

5 marks★★ 2×

Asked in: 2023 May Q4(c) [5] · 2025 May Q4(a) [5]

Definition

KNN classifies a new point by finding the K nearest training points and assigning the majority class among them. For regression it returns the average of the K neighbours.

Algorithm

1. Choose K and a distance metric.
2. For the query point q, compute d(q, x) for every training point x.
3. Sort the distances and pick the K smallest.
4. Count the class labels of those K neighbours.
5. Assign the majority class (or average for regression).

Example

Training points: (1,1) A, (2,2) A, (4,4) B, (5,5) B. Query q = (2.5, 2.5), K = 3.

PointClassDistance to qRank
(1,1)A√(1.5²+1.5²)=2.121
(2,2)A√(0.5²+0.5²)=0.712
(4,4)B√(1.5²+1.5²)=2.123
(5,5)B√(2.5²+2.5²)=3.544

The 3 nearest are (2,2) A, (1,1) A, (4,4) B → 2 votes A, 1 vote B → q is classified as A.

Choosing K

  • Small K (K = 1) → sensitive to noise, overfits.
  • Large K → smoother boundary, but may mix distant classes and underfit.
  • Use odd K for two classes to avoid ties; choose K by cross-validation.

Q3What are the advantages and disadvantages of K-NN?

6 marks★ 1×

Asked in: 2024 May Q3(b) [6]

Advantages

  • Simple — no training phase; just store the data.
  • Non-parametric — no assumption about the data distribution.
  • Naturally multiclass — majority vote extends to any number of classes.
  • Works for regression too (average of neighbours).
  • Adapts to complex, non-linear boundaries.
  • New data can be added without retraining.

Disadvantages

  • Slow prediction — computes distance to every training point: O(n·d) per query.
  • Memory heavy — stores the entire training set.
  • Curse of dimensionality — distances lose meaning in high dimensions.
  • Sensitive to scale — features must be normalised.
  • Sensitive to noise and outliers, especially K = 1.
  • K must be chosen; no built-in feature importance.
  • Imbalanced data → majority class dominates the vote.

4.3 Support vector machine (SVM)

SVM finds the widest possible “street” between two classes. The points on the edge of the street are the support vectors.

Q1Explain the basic principles of SVM. What are support vectors and how does SVM find the optimal hyperplane? Define separating hyperplane and margin with reference to SVM.

5–6 marks★★ 2×

Asked in: 2022 Nov Q4(c) [6 — separating hyperplane, margin] · 2025 Nov Q3(a) [5 — principles, support vectors, optimal hyperplane]

Separating hyperplane

A hyperplane is a decision boundary that separates the classes. In 2-D it is a line; in 3-D it is a plane; in n-D it is an (n−1)-dimensional flat surface.

w · x + b = 0

w is the normal vector (direction perpendicular to the plane); b is the bias (offset from the origin).

Margin

The margin is the distance between the hyperplane and the closest points of either class. For the canonical hyperplanes w·x+b = +1 and w·x+b = −1:

Margin = 2 / ‖w‖

SVM chooses the hyperplane with the maximum margin — the “widest street”.

Support vectors

The training points that lie exactly on the margin (or violate it in the soft-margin case). They are the only points that determine w and b; removing any other point does not change the boundary.

x2 | o o | o o -------+-----\-------- w·x+b = +1 | \ <- margin = 2/||w|| -------+-------\------ w·x+b = 0 | \ -------+---------\---- w·x+b = -1 | x x \ | x x x +---------------- x1 o = class +1, x = class -1 circled points on dashed lines = support vectors

Optimisation problem (hard margin)

Minimise  ½‖w‖²
subject to  yi(w·xi + b) ≥ 1   for all i

Minimising ‖w‖ maximises the margin 2/‖w‖. This is a convex quadratic program, so it has a unique global optimum.

Soft margin

Real data is not perfectly separable. Add slack variables ξi ≥ 0 and a penalty C:

Minimise  ½‖w‖² + C Σξi
subject to  yi(w·xi + b) ≥ 1 − ξi
  • C large → few training errors allowed → narrow margin → overfitting risk.
  • C small → wide margin, more errors allowed → underfitting risk.

Why SVM is popular

  • Maximum margin gives good generalization.
  • Works well in high dimensions.
  • Kernel trick handles non-linear boundaries.
  • Only support vectors matter → efficient.

Q2Explain with an example the variant of SVM: support vector regression (SVR).

5 marks★ 1×

Asked in: 2023 May Q3(a) [5]

Idea

SVR applies the SVM idea to regression. Instead of a separating line, it fits a tube of width 2ε around the predicted function. Points inside the tube incur no loss; only points outside are penalised.

ε-insensitive loss

Lε(y, f(x)) = max(0, |y − f(x)| − ε)

If the error is smaller than ε, the loss is zero. This makes SVR robust to small noise.

Optimisation

Minimise  ½‖w‖² + C Σ(ξi + ξi*)
subject to  yi − (w·xi + b) ≤ ε + ξi
           (w·xi + b) − yi ≤ ε + ξi*
           ξi, ξi* ≥ 0
  • ξ, ξ* — slack variables for points above/below the tube.
  • C — trade-off between a flat function and fitting the data.
  • ε — tube width; larger ε → fewer support vectors, smoother fit.

Example

House price prediction from area. With ε = 5 (lakh), a prediction 3 lakh away from the true price is ignored. A prediction 12 lakh away is outside the tube and contributes a loss of 12 − 5 = 7, which pushes the line towards it. The final model is a straight line (or kernel curve) that stays inside the tube wherever possible.

Kernel SVR

Replace w·x with a kernel K(xi, x) (RBF is common). The prediction becomes:

f(x) = Σ αi K(xi, x) + b

Only support vectors (points outside the tube) have αi > 0.

Q3Explain the kernel methods which are suitable for SVM.

6 marks★ 1×

Asked in: 2024 May Q4(b) [6]

Why kernels are needed

A linear SVM can only draw a straight boundary. Many datasets are not linearly separable. The kernel trick maps the data into a higher-dimensional space where a linear boundary exists, without explicitly computing the coordinates.

K(xi, xj) = φ(xi) · φ(xj)

Common kernels

KernelFormulaProperty / use
Linearxi·xjLinearly separable data; fast; interpretable
Polynomial(γ xi·xj + r)dCurved boundaries; degree d controls flexibility
RBF / Gaussianexp(−γ‖xi − xj‖²)Most popular; local, smooth boundary; γ controls width
Sigmoidtanh(γ xi·xj + r)Neural-network-like; not always PSD

Example

Points inside a circle (class A) and outside (class B) cannot be separated by a line in 2-D. Map (x,y) → (x, y, x²+y²). In 3-D the classes are separated by a horizontal plane. The RBF kernel does this mapping implicitly and measures similarity by distance.

Choosing a kernel

  • Start with linear if the number of features is large (text data).
  • Use RBF as the default for non-linear, low-to-medium-dimensional data.
  • Tune C and γ by cross-validation. Large γ → wiggly boundary (overfit); small γ → smooth (underfit).

4.4 Ensemble learning

An ensemble combines several weak/base models into one stronger model. This is the most repeated Unit-4 topic (6 instances).

Q1What do you mean by ensemble learning? Explain with an example. Why is ensemble learning used in ML? Write a short note on simple and advanced ensemble methods.

5–6 marks★★★★★★ 6×

Asked in: 2022 Nov Q3(c) [6 — simple/advanced] · 2023 May Q3(b) [6] · 2023 Nov Q3(b) [9] · 2024 May Q3(a) [5 — why] · 2025 May Q3(b) [6 — example] · 2025 Nov Q4(c) [6 — why]

Definition

Ensemble learning trains multiple models (called base learners) and combines their predictions by voting (classification) or averaging (regression). The combined model is usually more accurate and more stable than any single model.

Classification: ŷ = mode(h1(x), h2(x), …, hM(x))
Regression: ŷ = (1/M) Σ hm(x)

Why ensembles are used

  1. Reduce variance — averaging many models cancels their individual errors (bagging).
  2. Reduce bias — boosting focuses on hard examples and builds a stronger model.
  3. Improve accuracy — a group of weak learners can outperform a single strong learner.
  4. Robustness — less sensitive to noise, outliers and the choice of training sample.
  5. Avoid overfitting — random forest and bagging are much harder to overfit than a single deep tree.
  6. Handle heterogeneous data — different models capture different patterns (stacking).

Simple vs advanced ensembles (2022 Nov)

TypeMeaningExamples
Simple ensembleMany copies of the same base learner, combined by a fixed rule (vote/average)Bagging with decision trees, simple voting, averaging
Advanced ensembleHeterogeneous learners or a learned combination (meta-model), or sequential correctionStacking, blending, AdaBoost, gradient boosting, random forest, XGBoost

Example

Three decision trees classify a loan applicant: Tree 1 = reject, Tree 2 = reject, Tree 3 = approve. Majority vote → reject. If each tree is only 70% accurate but makes different errors, the majority is often more accurate than any single tree.

Types of ensemble

  • Bagging — parallel, bootstrap samples, average/vote (random forest).
  • Boosting — sequential, each model fixes the errors of the previous one (AdaBoost, gradient boosting).
  • Stacking — train a meta-model on the outputs of several base models.
  • Voting — hard vote (labels) or soft vote (probabilities).

Q2Differentiate between bagging and boosting. Explain bagging and boosting used in ensemble learning.

4–6 marks★★★ 3×

Asked in: 2023 May Q3(b) [6] · 2023 Nov Q3(a) [4] · 2025 May Q4(c) [6]

Bagging (Bootstrap Aggregating)

  • Draw M bootstrap samples (random sampling with replacement) from the training set.
  • Train one base model on each sample in parallel.
  • Combine by majority vote (classification) or average (regression).
  • Main effect: reduces variance; each sample is slightly different, so errors cancel.
  • Example: random forest = bagging + random feature selection.

Boosting

  • Train models sequentially. Each new model focuses on the examples the previous model got wrong.
  • Each model gets a weight α based on its accuracy; the final prediction is a weighted vote.
  • Main effect: reduces bias; a set of weak learners becomes a strong learner.
  • Example: AdaBoost, gradient boosting, XGBoost.

Q3Explain the random forest algorithm with an example and a suitable diagram.

5–9 marks★★★★ 4×

Asked in: 2022 Nov Q4(a) [5] · 2023 May Q4(b)(i) [6] · 2023 Nov Q3(b) [9] · 2025 Nov Q4(a) [5]

Definition

Random forest is an ensemble of decision trees. Each tree is trained on a bootstrap sample, and at every split only a random subset of features is considered. The forest combines the trees by majority vote (classification) or average (regression).

Algorithm

1. Choose the number of trees T and the number of features m
   (usually m = sqrt(d) for classification, d/3 for regression).
2. For t = 1 to T:
     a. Draw a bootstrap sample of size n from the training data.
     b. Grow a decision tree. At each node:
          - choose m features at random from all d features
          - split on the best feature among those m
     c. Do not prune the tree.
3. Predict:
     classification -> majority vote over T trees
     regression     -> average of T tree outputs

Diagram

Training data | +--------------+--------------+ | | | Bootstrap 1 Bootstrap 2 Bootstrap 3 | | | Tree 1 Tree 2 Tree 3 (random m (random m (random m features) features) features) | | | Class A Class A Class B +--------------+--------------+ | Majority vote | Class A

Example

Predict whether a customer will buy a product using age, income, city and previous purchases. Each tree sees a different bootstrap sample and a different random subset of features at each split. Tree 1 says “buy”, Tree 2 says “buy”, Tree 3 says “not buy” → forest predicts buy (2 out of 3).

Why it works

  • Bagging reduces variance by averaging many trees.
  • Feature randomness decorrelates the trees; without it, all trees would split on the same dominant feature.
  • No pruning is needed; individual trees may overfit, but the average does not.

Advantages / disadvantages

AdvantagesDisadvantages
High accuracy; robust to noise and outliersSlow and memory-heavy for many trees
Works for classification and regressionLess interpretable than a single tree
Handles high-dimensional dataMany hyperparameters (T, m, depth)
Gives feature importanceCan overfit small/noisy data if trees are deep

Hyperparameters

n_estimators (number of trees), max_features (m), max_depth, min_samples_leaf, oob_score (out-of-bag error).

Q4Write a short note on AdaBoost.

6 marks★ 1×

Asked in: 2023 May Q4(b)(ii) [6]

Definition

AdaBoost (Adaptive Boosting) combines many weak learners (usually decision stumps — one-split trees) sequentially. Each new learner focuses on the samples that the previous learners misclassified.

Algorithm

1. Start with equal weights: w_i = 1/n for i = 1..n.
2. For t = 1 to T:
     a. Train weak learner h_t on the weighted data.
     b. Compute weighted error:
          eps_t = sum of w_i for misclassified i.
     c. Compute learner weight:
          alpha_t = 0.5 * ln((1 - eps_t) / eps_t).
     d. Update sample weights:
          w_i = w_i * exp(-alpha_t * y_i * h_t(x_i))
     e. Normalise weights so they sum to 1.
3. Final prediction:
     H(x) = sign( sum alpha_t * h_t(x) ).

Key points

  • If a learner is better than random (ε < 0.5), α > 0; better learners get more vote.
  • Misclassified samples get larger weights, so the next learner concentrates on them.
  • If ε = 0.5, α = 0 (the learner is useless); if ε → 0, α → large.
  • Training error of the ensemble falls exponentially with the number of rounds.
  • Sensitive to noise and outliers because it keeps increasing their weights.

Small example

Three samples, all weight 1/3. Learner h1 misclassifies one sample: ε1 = 1/3.

α1 = ½ ln((1 − 1/3)/(1/3)) = ½ ln(2) = 0.3466

The misclassified sample’s weight becomes (1/3)e0.3466 ≈ 0.471, and the correct ones become (1/3)e−0.3466 ≈ 0.236. After normalisation, the hard sample has about 0.5 of the total weight, so the next learner is forced to focus on it.

5–6 marks★★★★ 4×

Variants of multiclass classification

(a) One-vs-All (OvA), also called One-vs-Rest (OvR)

  • Train C binary classifiers, one per class.
  • Classifier c is trained with class c as positive and all other classes as negative.
  • At prediction time, run all C classifiers and choose the class with the highest score/probability.
  • Example: classes A, B, C → classifiers “A vs {B,C}”, “B vs {A,C}”, “C vs {A,B}”.
  • Cost: C classifiers. Each classifier sees the full dataset.

(b) One-vs-One (OvO)

  • Train one binary classifier for every pair of classes.
  • Number of classifiers = C(C−1)/2.
  • At prediction time, each classifier votes for one of its two classes; the class with the most votes wins.
  • Example: classes A, B, C → “A vs B”, “A vs C”, “B vs C” (3 classifiers).
  • Each classifier is trained on only the data of its two classes → cheaper per classifier, but more classifiers.

Example with 4 classes

For A, B, C, D: OvA needs 4 classifiers; OvO needs 4×3/2 = 6 classifiers. If a new point gets OvO votes A=3, B=1, C=1, D=0, the prediction is A.

Q2Write a short note on handling imbalanced data in multiclass classification.

6 marks★ 1×

Asked in: 2025 May Q4(b) [6]

Problem

Imbalanced data has very different class frequencies (e.g. 95% class A, 5% classes B/C/D). A model can predict the majority class always and still get 95% accuracy, while completely failing on the minority classes. Multiclass imbalance is harder because there can be several minority classes.

Techniques

  1. Resampling
    • Oversampling — duplicate minority samples (or use SMOTE to create synthetic ones).
    • Undersampling — remove majority samples; risks losing information.
    • Hybrid — combine both (e.g. SMOTE + Tomek links).
  2. Class weights — set class_weight='balanced'; the loss penalises minority errors more.
  3. Cost-sensitive learning — assign a higher misclassification cost to minority classes.
  4. Threshold moving — lower the decision threshold for minority classes; tune per class.
  5. Better metrics — use macro F1, balanced accuracy, per-class recall, PR-AUC; do not rely on accuracy.
  6. Ensemble methods — BalancedBagging, EasyEnsemble, RUSBoost; each learner sees a balanced sample.
  7. One-vs-rest with calibration — train each class against the rest and calibrate probabilities.
  8. Data collection — the best long-term fix is to collect more minority samples.
Do not resample before splitting. Split train/test first, then resample only the training set. Otherwise the same sample can appear in both sets and the test score becomes optimistic.

Example

For classes A (950), B (30), C (20), plain accuracy is misleading. After class weighting and SMOTE, macro F1 might rise from 0.35 to 0.72 even though overall accuracy drops slightly — that is the correct trade-off.
